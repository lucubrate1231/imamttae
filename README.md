# 이맘때 자연

> 에베레스트에 오른 산악인이 아내와 무리 없이 다닌, 지금 가면 딱 좋은 자연의 명장면

이상호 작가의 브런치 연재 「아내와 살아서 가볼 100곳」을 바탕으로 만든 휴대폰 웹앱입니다.

- **지금 볼 만한 곳**: 이번 달 명장면을 지도에서 봅니다.
- **보고 싶은 명장면 찾기**: 단풍, 운해, 상고대처럼 보고 싶은 장면이 언제 어디 있는지 찾습니다.
- **올해 만난 명장면**: 명장면 10가지 도장을 모읍니다. 기록은 이 휴대폰에만 저장됩니다.

글과 사진의 저작권은 이상호 작가에게 있습니다. 전체 이야기는 [브런치](https://brunch.co.kr/@caed5ea4c3d74d9)에서 읽을 수 있습니다.

개발 방법은 [CLAUDE.md](CLAUDE.md)와 [docs/runbook.md](docs/runbook.md)를 보세요.
