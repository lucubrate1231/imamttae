# 홈 화면에 추가(F5) — 실기기 확인 (D33)

> 정한 날: 2026-10-04 · 결정: 기획 D33(PRD 3-6장) · 맡은 사람: Claude Code(준비·정리), 사용자(휴대폰으로 확인)
> 화면 글자·자리(카톡 안 '크롬으로 열기' 띠, 크롬의 설치 안내)는 디자인 세션 F5 PR이 정합니다. 이 문서는 **기술이 되는지**만 확인합니다.

## 왜 실기기로 확인하나
- 카카오톡 안 화면에서 바깥 브라우저로 넘기는 방법은 카카오 공식 문서가 없습니다. 컴퓨터 시험으로는 알 수 없습니다.
- 설치 창(beforeinstallprompt)이 뜨는지는 휴대폰 브라우저와 판에 따라 다릅니다.

## 준비된 것 (PR `claude/f5-pwa-base`)
- **매니페스트**(F5-AC1): 이름 '이맘때 풍경', 아이콘 이름 '이맘때', 전체 화면 표시. 아이콘은 디자인 세션 '두 봉우리와 해'(`public/brand/`, design-guide 11-6 — 10/7에 '나'안에서 바꿈).
- **서비스 워커**(F5-AC2): 크롬 자동 설치 창의 조건인 fetch 처리기가 있습니다. 화면을 열 때 늘 인터넷에서 새로 받고, 인터넷이 끊겼을 때만 마지막 화면을 보여 줍니다. github.io에서만 등록합니다.
  - 알파(`/imamttae/`)와 미리보기(`/imamttae/next/`)는 따로 설치되는 다른 앱입니다.
- **확인 페이지:** `https://lucubrate1231.github.io/imamttae/next/_review/a2hs-lab.html`
- **띠 다시 보기(확인용):** 주소 끝에 `?band=show`를 붙이면(예: `https://lucubrate1231.github.io/imamttae/next/?band=show`) 띠를 닫은 적이 있어도 다시 보여요. 닫음 표시는 그대로라 꼬리표 없이 열면 다시 숨어요. 카톡이 아닌 브라우저에서도 띠 모양을 볼 수 있고, 그때 띠를 누르면 넘어가지 않고 '열리지 않았나요?' 안내만 보여요.

## 확인 순서 (안드로이드 휴대폰)
1. **카카오톡 → 바깥 브라우저(①)**
   - 카톡 대화방(나와의 채팅)에 확인 페이지 주소를 보내고 눌러 엽니다.
   - 장면 몇 곳을 앱에서 [저장]한 뒤 확인 페이지로 돌아옵니다(같은 카톡 화면 안).
   - '① 카톡 → 기본 브라우저로 열기'를 누릅니다. 무엇이 열렸는지 적습니다.
   - 다시 카톡에서 열어 '① 카톡 → 크롬으로 열기(intent)'를 누릅니다. 무엇이 열렸는지 적습니다.
2. **저장한 곳 넘기기(②)**
   - 1에서 열린 크롬 화면의 '주소로 받은 장면'에 숫자가 보이는지 봅니다. [받은 ○곳을 저장한 곳에 합치기]를 누릅니다.
3. **설치 창(③)**
   - 크롬에서 확인 페이지를 열고 10초쯤 기다립니다. '③ 설치 창 띄우기'가 켜지면 눌러 설치합니다.
   - **저장 함께 쓰기:** 크롬에서 장면 두세 곳을 [저장]해 둡니다. 홈 화면에 생긴 '이맘때' 아이콘으로 앱을 열고 '저장한 곳' 탭을 봅니다. 같은 곳들이 보이면 크롬 탭과 설치한 앱이 저장을 함께 씁니다. 보이지 않으면 그대로 알려 주세요.
4. **삼성 인터넷(④)**
   - 삼성 인터넷으로 확인 페이지를 열고 10초 기다립니다. 설치 창 신호가 오는지 봅니다.
5. 단계마다 맨 아래 **[결과 복사]**를 눌러 Claude에게 보내 주세요.

## 알아 둔 것
- intent 주소는 형식상 `#` 뒤(앱 안 화면 주소)를 넘기지 못합니다. 장면 화면으로 바로 보내려면 주소 꼬리표로 넘겨야 합니다. 결과를 보고 정합니다.
- 넘기는 값은 **장면 번호뿐**입니다(`?carry=s-…,s-…`, 최대 100개). 받는 쪽은 장면 번호 모양만 받습니다.
