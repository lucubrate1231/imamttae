# 카카오 로컬 API 결과 저장 문제 — 무엇이 카카오에서 왔나 · 대안 비교 (10/5)

> 기획의 공개 전 법·개인정보 점검에서 찾은 급한 일이에요. 맡은 사람: Claude Code(개발 리드). **고를 것은 사용자**예요(아래 3장).
> 점검표 순서: **1번(이 문서) → 6번(공개 저장소·확인 페이지 훑기, 알파 전) → 8번(카카오 서버 사진·브런치 자동 수집, 비공개 베타 전)**.

## 0. 카카오 공식 답변 (데브톡, 2026년 8~9월)
| 날짜 | 답변 | 링크 |
|---|---|---|
| 8/26 | 로컬 API(장소 검색) 결과는 **어떤 형태로도 실시간 호출이 아닌 형태로 쓸 수 없음**. 한시적 저장도 안 됨. 이미 저장한 것은 지워야 함. 호출 패턴을 보고 어뷰징이면 제재할 수 있음. 따로 제휴 검토도 안 함 | [151343](https://devtalk.kakao.com/t/api/151343) |
| 9/4 | **위경도 좌표의 저장·활용은 허용하지 않음**, 실시간 호출로만 | [151497](https://devtalk.kakao.com/t/api/151497) |
| 8/26 | **장소 ID(와 장소 URL)만 저장하는 것은 허용**. 자기가 만든 데이터(이름·주소·좌표)는 그대로 두고 카카오 값으로 바꾸지 않는 방식 | [151335](https://devtalk.kakao.com/t/db-id/151335) |
| 9/17 | 사람이 확인·수정했어도 **로컬 API 결과에서 출발한 값이면 'API 결과 저장'**에 해당. 장소 ID·URL은 저장·활용 가능 | [151727](https://devtalk.kakao.com/t/id/151727) |

- **장소 ID로 좌표를 바로 받는 API는 없어요.** ID를 쓰려면 화면에서 장소 이름으로 다시 검색해 같은 ID를 고르는 방식(실시간 재검색)이에요.
- 무료 사용량([쿼터](https://developers.kakao.com/docs/ko/getting-started/quota)): 키워드 검색 하루 10만 건, 지도(웹) 하루 30만 건, 앱 전체 한 달 300만 건. **지도와 검색이 같은 앱 키**라서 제재를 받으면 지도도 멈출 수 있어요.

## 1. 지금 데이터에서 카카오 검색에서 온 값
좌표는 지금까지 `pipeline/geocode.ts`(카카오 **키워드로 장소 검색**)로 찾았어요(`docs/curation-guide.md` 16줄). 데이터에는 출처 칸이 없어서 값의 모양과 메모로 가렸어요.

| 칸 | 몇 곳 | 카카오에서 왔나 | 근거 |
|---|---|---|---|
| `spot`(풍경 지점 좌표 — 지도 점) | 앱 93곳(초안 95곳, 숨김 2) | **거의 전부** | 소수점 7자리(카카오 응답 모양) 87곳. 6·5자리 8곳도 카카오 검색 뒤 손본 값으로 보임 — 9/17 답변상 똑같이 해당 |
| `dest.lat/lng`(길찾기 목적지 좌표) | 93곳 | **거의 전부** | 소수점 7자리 91곳. 메모 23곳에 "카카오 지도에 ○○가 없어…", "주차장 이름이 검색되지 않아…" 같은 기록 |
| `dest.name`(목적지 이름) | 93곳 | **대부분** | '경상북도수목원 주차장1', '백무동제1주차장'처럼 카카오 장소 이름 그대로. 일부는 손으로 다듬음('벌말선착장(우도행 배)', '덕풍산장(용소골 들머리)') |
| 주소 | 0 | 저장 안 함 | `geocode.ts`가 화면에만 보여 줌 |
| `region`('경북 포항' 같은 시·군) | 93곳 | 아님(사람이 쓴 행정구역 이름) | 낮은 위험 — 카카오 응답을 옮긴 기록 없음 |

**들어 있는 곳**
- 저장소: `content/scenes/drafts.json`, `public/data/scenes.json`(앱이 읽는 파일), `tests/unit/geo.test.ts`(주전골·오색 주차장 좌표 2개)

**앱에서 쓰는 곳**
- `spot`: 첫 화면·풍경 찾기 지도 점, 장면과 목적지 15km 검사
- `dest`: 길찾기(티맵 기본 · 네이버지도 · 카카오맵)에 좌표와 이름을 넘김(CLAUDE.md 규칙 5: 이름이 아니라 좌표로)

## 2. 대안 비교
기준: **길찾기 오안내 0**(알파 종료 기준) · **화면 속도** · **카카오 무료 사용량** · 카카오 정책 위험.

| | ① 카카오 장소 ID만 저장 + 실시간 조회 | ② 저장해도 되는 출처로 좌표 다시 만들기 | ③ 섞기(②의 좌표 + 카카오 장소 ID) |
|---|---|---|---|
| 저장하는 것 | 카카오 장소 ID·URL, 우리가 쓴 검색어 | 공공데이터·오픈스트리트맵·직접 지정한 좌표와 이름 | ②의 좌표·이름 + 카카오 장소 ID |
| 지도 점(93곳) | 첫 화면을 열 때마다 장소 이름 **93번 검색**해야 점을 찍음 → 느림, 한 번에 몰리는 호출(제재 위험) | 지금처럼 바로 찍힘 | 지금처럼 바로 찍힘 |
| 길찾기 | 누를 때 검색 1번 → 그 좌표로 앱 열기. **카카오 결과를 티맵·네이버에 넘기는 것이 허용되는지는 확인 필요**(다른 지도 서비스와 섞어 쓰기) | 우리 좌표로 티맵·네이버·카카오맵 모두 | 티맵·네이버는 우리 좌표, **카카오맵은 장소 ID로 정확히** |
| 오안내 0 | 카카오 검색 결과가 바뀌거나 안 나오면 실패할 수 있음 | **우리가 하나씩 확인한 값이라 관리 가능**(대신 93곳 확인 필요) | ②와 같음 |
| 속도 | 느려짐(지도 점·길찾기 전에 검색) | 지금과 같음 | 지금과 같음 |
| 카카오 사용량 | 방문 1번에 최대 93건 → 하루 1,000번 방문쯤이면 무료 한도(10만)에 닿음 | 0 | 0(ID는 저장만) |
| 정책 위험 | 낮음(허용된 방식). 다만 호출 패턴은 조심 | **없음**(카카오 값을 안 씀) | 없음 |
| 일의 양 | 화면 코드 큼, 데이터는 ID 붙이기 | **데이터 93곳 다시 만들기 + 확인**(콘텐츠 세션), 코드 작음 | ②와 같음 + ID 붙이기 |

**②의 출처(저장해도 되는 것)**
- **공공데이터포털 '전국주차장정보표준데이터'**: 공영주차장 이름·위경도. 대부분 공공누리 1유형(출처 표시하면 상업 이용·변경 가능, 데이터마다 확인).
  - 우리 목적지 93곳 중 이름으로 공영주차장이 분명한 곳은 6곳뿐이에요. 수목원·공원·절·바닷가·국립공원 주차장(약 80곳)은 들어 있는지 하나씩 봐야 해요.
- **오픈스트리트맵(OSM)**: 주차장·탐방로 입구가 넓게 있어요. ODbL이라 **출처 표시('© OpenStreetMap contributors')와 데이터 공유 조건**이 붙어요(우리 데이터는 이미 공개).
- **직접 지정**: 사람이 카카오가 아닌 지도(오픈스트리트맵 등)나 항공사진에서 찍은 좌표는 우리 데이터예요. **카카오 지도를 보며 찍는 것은 피해요**(9/17 답변 취지).
- 네이버·구글 지오코딩도 저장을 막는 약관이라 쓰지 않아요.

### 추천: ③ 섞기 — 실제로는 ②를 하고, 카카오맵 길찾기만 장소 ID로
- 오안내 0을 우리가 관리할 수 있고, 속도·사용량이 지금과 같고, 카카오 정책 위험이 없어요.
- 카카오 장소 ID를 함께 두면 카카오맵으로 길찾기를 고른 사람은 카카오 장소 그대로 열려요(허용된 방식).
- 지도 점(`spot`)은 100m쯤 어긋나도 괜찮아서 빨리 바꿀 수 있어요. 시간이 걸리는 것은 길찾기 목적지(`dest`) 93곳 확인이에요.

## 3. 사용자가 정할 것
1. **대안:** ① · ② · ③(추천) 중 하나.
2. **지금 데이터를 언제 내릴지:** 카카오는 "바로 지워야" 한다고 했어요.
   - 가: 새 좌표가 준비될 때까지 둔다 — 앱은 그대로, 정책 위반 상태가 이어짐. 알파 전이라 보는 사람은 적음.
   - 나: 바로 내린다 — 지도 점과 길찾기가 새 좌표가 올 때까지 멈춤(미리보기·알파 모두).
3. **GitHub 기록:** 공개 저장소의 지난 커밋에도 좌표가 남아요.
   - 기록을 고쳐 쓰기(되돌릴 수 없고, Codex 폴더 등 모든 사본을 다시 받아야 함)
   - 저장소를 비공개로 바꾸기(GitHub Pages를 비공개 저장소에서 쓰려면 유료 요금제 — **비용 결정**)
   - 그대로 두기(새 커밋부터 깨끗하게)

## 4. 정해지면 할 일 (순서)
1. `pipeline/geocode.ts`를 더 쓰지 않게 막고 `docs/curation-guide.md`를 새 출처로 고침(바로 할 수 있음)
2. 새 출처로 `spot`·`dest`를 다시 만들기(콘텐츠 세션) — 데이터에 **출처 칸**(`source: 'public-parking' | 'osm' | 'manual'`)을 더해 다시 섞이지 않게 함
3. 길찾기 목적지 93곳을 티맵에서 하나씩 확인(오안내 0)
4. `tests/unit/geo.test.ts`의 좌표를 지어낸 값으로 바꾸기
5. 옛 좌표를 파일·공개 사이트에서 지우기(3장 2·3번 결정대로)
