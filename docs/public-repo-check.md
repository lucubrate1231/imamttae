## 사용자가 정할 것
1. **법규·내부 메모(1·2번)를 어디에 둘지:** 공개 저장소에서 빼서 Cowork 프로젝트(비공개)로 옮기면, 작가 확인 페이지는 그 메모 없이 보여야 해요(또는 확인 페이지도 비공개 쪽으로).
2. **확인 페이지(3번)를 미리보기에도 둘지:** 알파에서는 이미 뺐어요(아래). 미리보기는 작가 확인 때문에 두었는데, 1번 메모를 옮기면 함께 정해요.
3. **지난 기록(4·5번):** 저장소 기록 고쳐 쓰기 / 저장소 비공개(GitHub Pages 유료) / 그대로 두기 — 1번 문서의 3장과 함께 정하면 돼요.
