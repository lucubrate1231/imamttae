# 첫 화면 속도 재기

진짜 카카오 지도를 쓰는 첫 화면을 같은 방법으로 여러 번 재서 비교합니다. 화면 코드는 이 도구가 바꾸지 않습니다.

## 실행하기

처음에는 `npm ci`와 `npx playwright install chromium`을 실행합니다. 저장소 폴더에서 다음 명령을 실행하면 현재 미리보기를 각 경우 5번 잽니다.

```sh
node scripts/measure-speed.mjs
node scripts/measure-speed.mjs --runs 3
node scripts/measure-speed.mjs http://localhost:8080/ --runs 5 --case normal
node scripts/measure-speed.mjs --case kakao-blocked
node scripts/measure-speed.mjs --self-test
```

기본 주소는 `https://imamttae.site/next/`입니다. `--case`는 `all`(기본), `normal`, `slow4g`, `kakao-slow`, `kakao-blocked` 중 하나입니다. 횟수는 양의 정수입니다. 실제 지도와 비교하려는 도구이므로 `?map=fake` 주소는 받지 않습니다. 로컬 실제 지도에는 등록된 `localhost:8080` 주소와 공개 JS 키가 필요합니다. 키는 문서나 커밋에 쓰지 않습니다.

`--self-test`는 도구 자체의 검사입니다. 검사 전용 작은 페이지와 가짜 응답으로 시간 기록·지연·차단·새 브라우저 문맥을 확인합니다. 실제 앱의 속도 표와는 별개입니다. 작업 범위가 두 파일로 정해져 있어 검사를 스크립트 안에 두었습니다. 새 도구나 의존성은 추가하지 않았습니다.

## 네 가지 경우

| 이름 | 조건 |
|---|---|
| normal | 그대로 연결 |
| slow4g | 내려받기 1.6Mbps, 올리기 750kbps, 지연 150ms를 브라우저의 네트워크 설정으로 흉내 냄 |
| kakao-slow | dapi.kakao.com으로 가는 SDK 요청만 5초 늦춤 |
| kakao-blocked | dapi.kakao.com과 daumcdn.net 및 그 하위 주소의 요청을 막음 |

Pixel 7 설정에 화면 크기 390×844를 적용합니다. 매번 새 브라우저 문맥을 만들고 캐시와 서비스 워커를 끕니다. 실제 휴대폰의 처리 속도나 통신 품질까지 재현하는 검사는 아닙니다.

## 무엇을 재나

페이지를 연 순간부터 걸린 시간을 페이지 안에서 기록합니다. 데이터와 SDK는 응답이 끝난 시각을, 그림과 핀은 조건을 처음 확인한 시각을 씁니다. Playwright와 왕복하는 시간은 측정값에 더하지 않습니다.

| 칸 | 확인하는 조건 |
|---|---|
| 데이터 | data/scenes.json 응답을 끝까지 받음 |
| 사진 카드 | 첫 `.rail .big .photo img`가 완전히 내려왔고, 실제 그림 크기가 있으며 숨겨져 있지 않음 |
| 지도 조각 | `.mapsec .kmap` 안의 daumcdn.net 그림 조각 하나 이상이 완전히 내려와 보임 |
| 핀 | `.mapsec .kmap .pin` 하나 이상이 보임 |
| SDK | dapi.kakao.com 첫 요청의 응답이 끝남(참고용) |

15초 안에 조건을 확인하지 못하면 `—`입니다. 오류나 차단 때문에 한 칸이 비어도 다음 경우를 계속 잽니다. 카카오를 막았을 때 지도 조각·핀·SDK가 `—`인 것은 예상한 결과입니다.

표는 **가운데 값(가장 느린 값)**이며 단위는 초입니다. 실패한 회차를 빼서 결과가 빨라 보이지 않도록, 미확인 값은 가장 뒤에 놓고 가운데 값을 계산합니다. 한 번이라도 미확인이면 가장 느린 값은 `—`입니다. 일부만 확인된 경우 완료 횟수도 표시합니다.

지도 조각 하나가 뜬 시각을 재므로 지도 전체가 확대·배치를 마친 시각이나 화면의 모든 큰 그림이 뜬 시각과는 다릅니다.

## 개발 확인 기록

구현 전에 옵션·표 검사 14개가 실패했고, 브라우저 검사를 더한 뒤 총 20개가 실패했습니다(Node 검사 집계에는 묶음 검사 1개가 포함됩니다). 구현 뒤 20개가 모두 통과했습니다. 네 경우를 끝까지 돌리고 카카오 차단에서도 사진 카드 시간을 기록하는 완성 기준을 실제 앱에서도 확인했습니다.
