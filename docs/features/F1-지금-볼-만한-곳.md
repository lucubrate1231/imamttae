# F1. 지금 볼 만한 곳 (첫 화면)

**한 줄:** 앱을 열면 이번 달에 가면 좋은 자연 명장면이 큰 사진으로 넘어가고, 아래 지도가 그곳이 어디인지 보여 줍니다.

> 화면 구성은 **B안(사진 + 지도)**으로 정했습니다(사용자 결정). 시안: `/next/_review/proto.html?v=b`

## 화면 구성 (위에서 아래로)
1. **달 띠**: 앱 이름과 부제는 두지 않습니다(사용자 결정). 화면 맨 위가 바로 달 띠입니다.
2. **큰 사진 카드**: 옆으로 넘깁니다. 사진은 3:2이고, 카드에는 명장면 꼬리표, 장면 이름, 지역, 가장 좋은 때를 보여 줍니다.
3. **작은 지도**: 카드와 함께 움직입니다.
4. **아래 메뉴**: 글자 메뉴 3개(지금 / 명장면 찾기 / 수첩)

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F1-AC1 | 앱을 열면 **한국 날짜 기준 이번 달**이 선택되어 있고, 달 띠의 이번 달이 화면 가운데로 와 있습니다. 휴대폰 시간대가 달라도 같습니다. | 단위·화면 |
| F1-AC2 | 달 띠에는 1월부터 12월까지 12개가 있고, 누르는 곳은 48px 이상입니다. | 화면 |
| F1-AC3 | 고른 달이 **'가장 좋은 때'에 들어가는 이야기 장면**이 큰 사진 카드로 나옵니다. 12월~2월처럼 해를 넘는 기간도 맞게 나옵니다. *(결정 필요 1)* | 단위·흐름 |
| F1-AC4 | 고른 달에 다녀온 **저장글**은 카드 띠 맨 뒤에 **준비 중 카드**로 나옵니다. 사진 없이 점선 테두리에 이름과 다녀온 날만 보여 주고, 지도에는 점선 점으로 표시합니다. | 데이터 규칙·화면 |
| F1-AC5 | **카드를 넘기면 지도가 먼저 우리나라 전체를 보여 주고, 약 1.5초 뒤 그 장소로 확대**합니다(사용자 제안). 처음 열 때도 같습니다. 휴대폰에서 '움직임 줄이기'를 켠 분에게는 확대된 상태로 바로 보여 줍니다. | 흐름·실제 지도 |
| F1-AC6 | 지도에서 다른 장소 점을 누르면 그 카드로 넘어갑니다. 고른 장소만 이름표를 보여 줍니다. | 흐름 |
| F1-AC7 | 카드를 누르면 장면 상세(F2)가 열립니다. | 흐름 |
| F1-AC8 | 이야기가 하나도 없는 달은 빈 화면 대신 "2월은 아직 이야기가 없어요" 안내와 **가까운 달의 명장면**을 보여 줍니다(예: 1월 상고대, 3월 매화). | 화면 |
| F1-AC9 | 달을 바꾸면 주소가 `#/month/11`처럼 바뀌고, 뒤로 가기를 누르면 이전 달로 돌아갑니다. | 흐름 |
| F1-AC10 | 카카오 지도를 못 불러오면 지도 자리에 "지도를 불러오지 못했어요"라고 알립니다. 사진 카드는 그대로 씁니다. | 화면·흐름 |

## 이번에 하지 않는 것
- **내 위치에서 거리 보기**: 시안에서 만들어 봤으나 지금은 빼기로 했습니다(사용자 결정). 위치 권한을 묻지 않습니다.
- 가까운 순 보기, 절정 알림 (V2)
- 일반 추천지 '가볼 곳' (넣지 않음)

## 나중에 같이 검토
- 웹앱이라 위아래가 짧게 느껴지는 문제를 검토합니다. 앱 이름·부제는 이미 없앴습니다.
- 남은 후보는 두 가지입니다.
  - 스크롤하면 주소창이 접히게 하기
  - '홈 화면에 추가'로 주소창 없이 열기 (→ [F5](F5-홈-화면에-추가.md))
