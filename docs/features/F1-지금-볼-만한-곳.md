# F1. 지금 볼 만한 곳 (첫 화면)

**한 줄:** 앱을 열면 이번 달에 가면 좋은 자연 풍경이 큰 사진으로 넘어가고, 아래 지도가 그곳이 어디인지 보여 줍니다.

> 화면 구성은 **B안(사진 + 지도)**으로 정했습니다(사용자 결정). 10/3 결정(제철·기록 구분)을 넣은 **v2 시안**: `/next/_review/v2.html` — 사용자 확인 대기

## 화면 구성 (위에서 아래로, 한 페이지를 위아래로 스크롤)
1. **머리와 달 띠** (10/3 2차 코멘트): 작은 글씨 **'이상호 대장의 추천'** → 큰 글씨 **'10월에 만나는 자연'** → 달 띠 순서입니다. 아래로 스크롤하면 큰 제목은 함께 올라가고, 대신 **'N월에 만나는 자연'만 담은 작은 제목 막대**(18px, 가운데, 얇은 선)가 위에 서서히 나타납니다(큰 제목을 그대로 붙이면 투박해서). 앱 이름·부제는 두지 않습니다. 바탕에 계절 색이 옅게 깔립니다.
2. **제철 큰 사진 카드**: 옆으로 넘깁니다(옆 카드가 살짝 보이는 것으로 더 있음을 알림, 페이지 표시는 두지 않음). 사진은 3:2이고, 반투명한 풍경 꼬리표, 장면 이름, 지역, **'추천 시기 10월 중순~하순'**(앞에 작은 달력 아이콘), 그 아래 한 단계 약하게 **'단풍 시기는 해마다 달라져요'**(종류별 문구)를 보여 줍니다. 계절말(늦가을 등)과 '제철' 딱지는 카드에 쓰지 않습니다(10/3 코멘트).
   - 계절 색 띠는 **달 띠부터 제철 카드 끝까지 제철 구역 전체**를 덮습니다. 카드 중간에서 끊기지 않게 합니다(10/3 사용자 결정 — 띠를 제목까지만 두는 안보다 덜 사무적으로 보임).
3. **작은 지도**: 손으로 움직이지 않습니다(페이지 스크롤과 다투지 않게). 카드를 넘기면 전국 → 그 장소로 확대합니다. 제철은 계절 색 점, 다녀온 기록은 회색 점입니다.
4. **다녀온 기록**: "10월에 다녀온 기록". 작은 사진과 회색 글씨로 톤을 낮춘 목록입니다.
5. **홈 화면에 두기**(F5 입구), 작은 글씨 '이 앱 이야기' + **'60대 부부의 100곳 여행 약속'** 링크(브런치 첫 글로 연결)
6. **아래 메뉴**: 글자 메뉴 3개(지금 / 풍경 찾기 / 내 수첩), 화면 아래에 붙어 있음
