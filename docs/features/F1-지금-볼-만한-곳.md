# F1. 지금 볼 만한 곳

**한 줄:** 앱을 열면 이번 달에 가면 좋은 자연 명장면이 지도에 떠 있습니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F1-AC1 | 앱을 열면 **한국 날짜 기준 이번 달**이 선택되어 있습니다. 휴대폰 시간대가 달라도 같습니다. | 단위·화면 |
| F1-AC2 | 위쪽에 **달 띠 12개**(1월~12월)가 있고, 이번 달이 화면 가운데로 와 있습니다. 각 달에는 그달 이야기 수가 작게 적혀 있습니다(예: "10월 · 7"). | 화면 |
| F1-AC3 | 고른 달이 **'가장 좋은 때'에 들어가는 이야기 장면**이 지도에 **사진 핀**으로 나옵니다. 12월~2월처럼 해를 넘는 기간도 맞게 나옵니다. *(결정 필요 1)* | 단위·흐름 |
| F1-AC4 | 고른 달에 다녀온 **저장글**은 **준비 중 핀**(점선)으로 나옵니다. 이름과 다녀온 날만 보여 줍니다. | 데이터 규칙·화면 |
| F1-AC5 | 달을 바꾸면 그달 핀이 모두 보이게 지도가 맞춰집니다. 가까이 붙은 핀은 숫자 묶음으로 보이고, 누르면 펼쳐집니다. | 흐름·실제 지도 |
| F1-AC6 | 지도 아래에 그달 장면이 **가로 카드 띠**로도 나옵니다. 카드를 누르면 핀을 누른 것과 같습니다. 지도를 다루기 어려운 분을 위한 길입니다. | 흐름 |
| F1-AC7 | 핀이 하나도 없는 달은 비워 두지 않습니다. "2월은 아직 이야기가 없어요" 안내와 함께 **가까운 달의 명장면**을 권합니다(예: 1월 상고대, 3월 매화). | 화면 |
| F1-AC8 | 달을 바꾸면 주소가 `#/month/11`처럼 바뀝니다. 뒤로 가기를 누르면 이전 달로 돌아갑니다. | 흐름 |
| F1-AC9 | 카카오 지도를 못 불러오면 "지도를 불러오지 못해 목록으로 보여 드려요"라고 알리고, 같은 장면을 목록으로 보여 줍니다. | 화면·흐름 |
| F1-AC10 | 이야기 핀과 준비 중 핀은 모양으로 구별되고, 지도 위 작은 범례로 설명합니다. 색이 아니라 **모양**(사진 / 점선)으로 구별하므로 색약이어도 알아볼 수 있습니다. | 화면·접근성 |
