# F3. 보고 싶은 풍경 찾기

**한 줄:** "단풍 보고 싶다"를 고르면 언제(달)와 어디(지도)가 함께 나옵니다.

## 풍경 13가지 (작가 확인 필요)
10/3 사용자 결정으로 11~13번을 더했습니다. 10가지에 맞지 않는 계곡·숲·바다 장면이 17곳 있었습니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F3-AC1 | 첫 화면의 **"풍경 찾기"** 버튼을 누르면 13가지 풍경 버튼이 나옵니다(`#/find`). | 흐름 |
| F3-AC2 | 하나를 고르면(`#/find/danpung`) **지도에는 그 풍경 이야기 핀 전체**가, **달 띠에는 그 풍경을 볼 수 있는 달 표시**가 나옵니다. | 화면·흐름 |
| F3-AC3 | 아래 목록은 **이번 달부터 가까운 순서의 가장 좋은 때**로 정렬됩니다. 예: 단풍 → 설악 주전골(10월 중순) → 내장산(11월 초). **다녀온 기록** 장면은 제철 장면 뒤에 작게 나옵니다. | 단위 |
| F3-AC4 | **발행된 이야기만** 나옵니다. 준비 중 장면은 풍경 종류를 모르므로 나오지 않습니다. | 데이터 규칙·화면 |
| F3-AC5 | 이야기가 아직 없는 풍경은 흐리게 보이고 "아직 이야기가 없어요"라고 적습니다. 눌러도 빈 지도가 나오지 않습니다. | 화면 |
| F3-AC7 | **지역으로 고르기(10/3 사용자 결정):** 풍경 버튼 아래에 권역 칩 한 줄을 둡니다 — 강원 · 경상 · 전라 · 충청 · 수도권(장면이 없는 권역은 숨김, 칩마다 장면 수 표시). 권역을 고르면 그 지역 장면이 달과 상관없이 모두 나오고, 추천 시기가 지금과 가까운 순으로 정렬되며, 지도는 그 권역으로 확대됩니다. 풍경 종류와 함께 고를 수 있습니다. | 단위·화면·흐름 |
| F3-AC8 | 첫 화면(지금)에는 지역 고르기를 두지 않습니다(한 달에 보이는 장면이 적어 비기 쉬움). '내 위치 근처'는 위치 권한이 필요해 V2에서 검토합니다. | — |
| F3-AC6 | 고른 풍경을 해제하면 원래의 '지금 볼 만한 곳' 화면으로 돌아갑니다. | 흐름 |
