# F3. 보고 싶은 풍경 찾기

**한 줄:** "단풍 보고 싶다"를 고르면 언제(볼 수 있는 때)와 어디(지도)가 함께 나옵니다.

> **화면(10/3 밤 사용자 선택: A안 '사진 타일', 3차 수정까지 반영):** 디자인 캔버스 [이맘때 자연 — 풍경 찾기 스케치](https://claude.ai/artifact/RcKZdmgsTKWB8aH1LmV7iE)의 **A안** 세 화면이 기준입니다(B·C안은 비교용). 공통 화면 규칙은 [`docs/design-guide.md`](../design-guide.md) 8장.
> 캔버스는 비공개라 사용자 계정에서만 열립니다. 다른 사람(또는 다른 세션)은 이 문서와 design-guide만 보고도 만들 수 있게 적었습니다.

## 화면 세 가지 (A안)
1. **풍경 고르기 (`#/find`)** — 머리('풍경 찾기' / '어떤 풍경이 보고 싶으세요?' / '고르면 언제, 어디서 볼 수 있는지 알려 드려요.') → **N월에 좋은 풍경**(첫째는 큰 사진, 나머지는 2열 사진 타일) → **지역으로 고르기**(권역 칩) → **다른 때 풍경**(2열 사진 타일) → 아래 메뉴.
2. **풍경을 고른 뒤 (`#/find/danpung`)** — '‹ 풍경 찾기' → 제목(풍경 이름) → **볼 수 있는 때 한 줄**(예: ● 지금 한창 · 10~11월에 가장 고와요) → 권역 칩 → 지도 → **가까운 때부터** 목록 → **작가 부부가 다녀온 곳**.
3. **이야기가 적은 풍경** — 2와 같고, 제철 장면이 하나도 없으면 안내 문구와 **지금 함께 보기 좋은 풍경** 타일이 붙습니다(F3-AC9). 예: 억새·갈대(2곳 모두 다른 계절 사진).

## 계산에 쓰는 말
- **볼 수 있는 때(풍경):** 그 풍경 장면들의 **추천 시기(`best.from~to`)를 모은 달**입니다. 다녀온 달이 아닙니다. 추천 시기가 없는 장면은 빼고, 모든 장면이 '일 년 내내'면 '언제나'입니다.
  - 예(83곳): 단풍·은행 10~11월, 억새·갈대 10~11월(두 곳 다 다른 계절 사진이어도 추천 시기 기준), 바다 절경 언제나.
- **N월에 좋은 풍경:** 그 풍경 이야기 중 **절반 이상**이 추천 시기에 이번 달을 품는 풍경(일 년 내내인 장면은 세지 않음). 이번 달을 품는 장면이 많은 순. 예(10월): 단풍·은행 9 → 운해·물안개 8 → 억새·갈대 2. 계곡·폭포(12곳 중 1곳)는 '다른 때'로.
- **다른 때 풍경 순서:** 볼 수 있는 때가 **다음 달부터 가까운 순**(시작하는 달 기준, 같으면 위 표의 순서), '언제나'인 풍경은 맨 뒤. 예(10월): 설경·상고대(11~2월) → 매화·산수유(3월) → 벚꽃 → 진달래·철쭉 → 신록·초원 → 여름꽃 → 계곡·폭포 → 꽃무릇·가을꽃 → 일출·낙조 → 바다 절경.

| F3-AC2 | 하나를 고르면(`#/find/danpung`) **지도에는 그 풍경 이야기 핀 전체**가, 제목 아래에는 **볼 수 있는 때 한 줄**이 나옵니다. 한 줄은 **안내만** 하고 누르는 기능이 없습니다(10/3 사용자 결정). 모양은 상태 점 + 문장입니다: 이번 달이 볼 수 있는 때 안이면 '● **지금 한창** · 10~11월에 가장 좋아요', 다음 달에 시작하면 '○ **곧** · 11~2월에 가장 좋아요', 그 밖에는 점 없이 '3월에 가장 좋아요', 언제나면 '언제나 좋아요'. 12달 표나 달별 장면 수는 두지 않습니다(통계표처럼 딱딱해서, 10/3 사용자 결정). | 단위·화면 |

| F3-AC10 | **누르는 것과 알려 주는 것을 모양으로 나눕니다(10/3 사용자 결정):** '지금 한창', '지금', '곧' 같은 상태 표시는 알약(칩) 모양을 쓰지 않고 점 + 글자로 씁니다(design-guide 8-2). 칩 모양은 누르는 것(권역 칩, 달 띠, 아래 메뉴)에만 씁니다. | 화면 |

## 정해야 할 것 (사용자·기획)
1. **'지금' 묶음 안의 순서:** 지금 계산(Codex 일 1)은 같은 거리면 이름 가나다순입니다. 화면 시안은 **추천 시기가 먼저 끝나는 곳 먼저**(10월 중순~하순 → 10월 말~11월 초), 같으면 가나다순으로 그렸습니다(첫 화면 F1의 '곧 끝나는 곳' 정렬과 같은 생각). ★ 추천: 먼저 끝나는 곳 먼저.
2. **볼 수 있는 때 계산:** Codex 일 1의 `monthsForType`은 제철 장면의 추천 시기 + 작가 부부가 다녀온 곳의 **다녀온 달**을 모읍니다(옛 '달 띠 표시용'). 새 화면의 한 줄은 **추천 시기만** 모아야 합니다(억새·갈대가 '3·8월'로 나오면 틀림). `monthsForType`을 바꿀지, 새 함수를 더할지.
3. **한 줄 문장의 끝말:** 풍경마다 다르게 쓸지(시안: 단풍 '가장 고와요', 억새 '가장 좋아요') '가장 좋아요' 하나로 통일할지. 풍경별로 쓰면 13줄 문구표를 만들어 작가님 확인을 받습니다.
