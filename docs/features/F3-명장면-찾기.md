# F3. 보고 싶은 명장면 찾기

**한 줄:** "단풍 보고 싶다"를 고르면 언제(달)와 어디(지도)가 함께 나옵니다.

## 명장면 10가지 (작가 확인 필요)
| 순서 | 명장면 | 주소 이름 |
|---|---|---|
| 1 | 매화·산수유 | maehwa |
| 2 | 벚꽃 | beotkkot |
| 3 | 진달래·철쭉 | jindallae |
| 4 | 여름꽃 | yeoreumkkot |
| 5 | 꽃무릇·가을꽃 | kkotmureut |
| 6 | 단풍·은행 | danpung |
| 7 | 억새·갈대 | eoksae |
| 8 | 운해·물안개 | unhae |
| 9 | 일출·낙조 | ilchul |
| 10 | 설경·상고대 | seolgyeong |

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F3-AC1 | 첫 화면의 **"명장면 찾기"** 버튼을 누르면 10가지 명장면 버튼이 나옵니다(`#/find`). | 흐름 |
| F3-AC2 | 하나를 고르면(`#/find/danpung`) **지도에는 그 명장면 이야기 핀 전체**가, **달 띠에는 그 명장면을 볼 수 있는 달 표시**가 나옵니다. | 화면·흐름 |
| F3-AC3 | 아래 목록은 **이번 달부터 가까운 순서의 가장 좋은 때**로 정렬됩니다. 예: 단풍 → 설악 주전골(10월 중순) → 내장산(11월 초). | 단위 |
| F3-AC4 | **발행된 이야기만** 나옵니다. 준비 중 장면은 명장면 종류를 모르므로 나오지 않습니다. | 데이터 규칙·화면 |
| F3-AC5 | 이야기가 아직 없는 명장면은 흐리게 보이고 "아직 이야기가 없어요"라고 적습니다. 눌러도 빈 지도가 나오지 않습니다. | 화면 |
| F3-AC6 | 고른 명장면을 해제하면 원래의 '지금 볼 만한 곳' 화면으로 돌아갑니다. | 흐름 |
