# 기능별 완성 기준 (v0.1 알파)

각 기준에는 번호(예: F2-AC3)가 있고, 번호마다 자동 테스트가 하나 이상 붙습니다.
**사용자가 읽고 확인한 기준만** 구현합니다. 고칠 곳은 문장 옆에 메모해 주시면 됩니다.

> **디자인 확정(10/3 밤):** 사용자가 시안 v2(1~7차 코멘트 반영, 사진 움직임 포함)를 OK했습니다. F1·F2의 화면 기준은 이 시안과 `docs/design-guide.md`를 따릅니다.
> **풍경 찾기(F3) 화면 선택(10/3 밤, 디자인 세션):** 스케치 3안 중 사용자가 **A안 '사진 타일'**을 골라 3차까지 다듬었습니다. F3 문서와 `docs/design-guide.md` 8장에 반영했습니다. 10/4 기획 점검(D21~D23: '지금 제철', '이번 달에 좋은 풍경'은 1곳 이상, '언제나' 구역 따로, 먼저 끝나는 곳 먼저)도 반영했습니다.
> **화면 글자(10/4 D28~D30, 디자인 세션):** 앱 사용자 글자는 `docs/design-guide.md` **10장 '화면 글자 표'**가 기준입니다 — [저장]/[저장됨], 상태 표시 '지금 좋아요'(문장은 '지금 가기 좋아요'), 화면에서 '제철'·'작가 부부'를 쓰지 않음. F1·F2 문서와 코드의 글자는 Claude Code가 이 표대로 맞춥니다. 이 문서들의 '제철 장면'·'작가 부부가 다녀온 곳'은 장면 종류를 가리키는 내부 말이라 그대로 둡니다.

## 모든 기능에 공통
- **C-1:** 휴대폰 360px·390px 폭에서 가로 스크롤 없이 보입니다. 320px에서도 깨지지 않습니다.
- **C-2:** 본문 글자는 18px 이상, 누르는 곳은 48px 이상입니다. 글자를 130%로 키워도 겹치지 않습니다.
- **C-3:** 접근성 검사(axe) 위반이 0입니다. 화면 읽기 프로그램으로 핀과 버튼 이름을 들을 수 있습니다.
- **C-4:** 지도·사진·저장소가 실패해도 앱이 멈추지 않고, 무엇이 안 되는지 쉬운 말로 알립니다.
- **C-5:** 용어는 **자연 풍경 / 이야기 / 준비 중 / 초안 / 가장 좋은 때 / 다녀온 날 / 가는 곳**으로 통일합니다.
- **C-8:** 라이트 모드만 둡니다. 블러 효과는 쓰지 않습니다(사용자 결정).
- **C-9 글꼴(10/3 사용자 결정, '장면 확인표'와 같은 규칙):** 정보·버튼은 고딕 **IBM Plex Sans KR**, 제목(맨 위 제목·장면 이름·구역 제목)과 **작가의 한마디**는 명조 **고운바탕 굵게**. 둘 다 무료 공개 글꼴(OFL)이고, 화면에 쓰인 글자 묶음만 내려받습니다.
- **C-6:** 주소(링크)를 카카오톡으로 보내면 받은 사람도 같은 화면이 열립니다. 뒤로 가기 버튼이 예상대로 작동합니다.
- **C-7:** 첫 화면이 휴대폰 보통 속도(4G)에서 3초 안에 뜹니다. 앱 JS는 50KB, 데이터는 120KB 이하입니다.
- **C-10 의견 보내기(D46, 10/6 — 알파·비공개 베타를 합친 D45로 출시 전에):** 첫 화면 맨 아래('이 앱 이야기' 아래)와 저장한 곳 맨 아래에 **'의견 보내기 · 불편한 점, 틀린 정보, 바라는 점 무엇이든 좋아요.'** 카드, 장면 상세 본문 끝에 **'이곳 정보가 달라졌나요?'** 줄이 있습니다. 누르면 구글 폼이 새 창으로 열리고, 장면 상세에서는 폼에 장면 이름이 미리 들어갑니다. 폼 주소는 설정 한 곳에서 바꿉니다. 홈 화면 아이콘으로 열어도 보입니다. 통계 `feedback`에 어디서 눌렀는지를 남깁니다. (`docs/design-guide.md` 12-1·10-8, 캔버스 ⑨줄)
- **C-11 개인정보 안내(D45, 법·개인정보 점검 7번):** 첫 화면 맨 아래 바닥줄 '개인정보 안내'와 저장한 곳 안내 상자의 '개인정보 안내 보기 ›'로 개인정보 안내 화면(`#/privacy`)이 열립니다. 뒤로 가기로 돌아오고, 문의 이메일이 글자로 보이며 [메일 쓰기]로 메일 앱이 열립니다. 글은 기획 초안, 이메일은 사용자가 정합니다. (`docs/design-guide.md` 12-2·10-8)

## 기능 ①을 만들기 전에 정해 주실 것 (제 추천은 ★)
1. ~~핀을 어느 달에 보여 줄까요?~~ **정함(10/3 사용자 결정):** 사진은 작가가 다녀온 계절 그대로 보여 줍니다. 다녀온 달이 가장 좋은 때 안이면 **제철**(그 철 내내 크게), 아니면 **작가 부부가 다녀온 곳**(지도 범례 '작가 부부 방문', 다녀온 달에만 작게)입니다. '다녀온 기록'은 내 기록과 헷갈려 10/3 3차 결정으로 바꿨습니다. (F1-AC3, F1-AC11)
2. ~~장면 카드에서 바로 '봤어요' 도장?~~ **정함(10/3):** 카드에는 **가고 싶어요(저장)** — 10/4 D28로 버튼 글자는 [저장]. 수첩은 '가고 싶은 곳 → 다녀왔어요 → 도장' 흐름이고, 담지 않은 곳을 우연히 다녀와도 도장판에서 바로 찍을 수 있습니다(F4-AC2·AC3). → **10/4 D24로 바뀜:** 셋째 탭은 **'저장한 곳'**(가고 싶은 곳이 위), 도장은 저장한 장면의 [다녀왔어요]로 **장소**에 찍히고 다녀온 곳은 해마다 도장 모음입니다. 풍경 도장판과 '봤어요'는 없어졌습니다(F4).
5. ~~지역 필터?~~ **정함(10/3):** 두 번째 탭에 권역 칩으로 넣습니다(F3-AC7). 첫 화면에는 넣지 않습니다.
6. ~~두 번째 탭 이름~~ **정함(10/3):** '명장면'이 영화 용어 같다는 의견에 따라 앱 전체에서 **'풍경'**으로 바꿉니다. 탭은 **풍경 찾기**, 종류는 **풍경 13가지**, 수첩은 **올해 만난 풍경**(10/4 D24로 셋째 탭 이름은 **'저장한 곳'**). (10/3 밤 추가: 풍경 수는 늘 수 있으니 **화면에는 '13가지'를 쓰지 않습니다.** 문서에서 종류를 가리킬 때만 씁니다.)
3. ~~공유 버튼을 알파에 넣을까요?~~ **정함(10/4, D1):** 알파에 넣습니다(F2-AC9). 카카오톡 미리보기는 알파에서는 앱 공통 그림이고, 장면별 미리보기는 백로그(D15)입니다.
4. **풍경 13가지 이름 확정.** 10/3에 계곡·폭포, 바다 절경, 신록·초원을 더했습니다(사용자 결정). 이름은 작가님 확인이 필요합니다(F3 표).
