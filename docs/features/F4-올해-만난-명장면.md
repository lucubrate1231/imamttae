# F4. 올해 만난 명장면 (수첩)

**한 줄:** 국립공원 스탬프처럼, 올해 만난 명장면 10가지에 도장을 모읍니다. 로그인 없이 이 휴대폰에만 저장합니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F4-AC1 | 수첩 화면(`#/stamps`)에 명장면 10칸이 있고, 맨 위에 **"올해 4가지 명장면을 만났어요"**처럼 진행 상황이 나옵니다. | 화면 |
| F4-AC2 | 칸을 누르고 **"봤어요"**를 누르면 오늘 날짜와 함께 도장이 찍힙니다. 잘못 찍었으면 같은 칸에서 취소할 수 있습니다. | 화면·흐름 |
| F4-AC3 | 장면 카드에도 "이 명장면 봤어요" 버튼이 있어 바로 도장을 찍을 수 있습니다. *(결정 필요 2)* | 흐름 |
| F4-AC4 | 아직 못 만난 칸을 누르면 **"어디서 볼 수 있나요?"**로 그 명장면 찾기(F3)가 열립니다. | 흐름 |
| F4-AC5 | 새로고침하거나 며칠 뒤 다시 와도 도장이 남아 있습니다. | 흐름 |
| F4-AC6 | 한국 날짜로 새해 1월 1일이 되면 올해 수첩이 새로 시작됩니다. 지난해 도장은 '지난해' 아래에 접어 보관합니다. | 단위 |
| F4-AC7 | 화면에 **"이 휴대폰에만 저장돼요"**라고 밝힙니다. 휴대폰을 바꾸거나 브라우저 기록을 지우면 사라지고, 부부가 함께 쓸 수는 없습니다. | 화면 |
| F4-AC8 | 저장이 막힌 브라우저(사생활 보호 모드 등)에서는 "이 브라우저에서는 도장이 저장되지 않아요"라고 알립니다. 화면은 그대로 작동합니다. | 단위·화면 |

## 이번에 하지 않는 것
- 장소별 '다녀왔어요' 도장, 여러 기기에서 이어 쓰기, 부부 공유 (로그인이 필요해서 V2에서 검토)
