# F5. 홈 화면에 추가 (앱처럼 쓰기)

**한 줄:** 휴대폰 홈 화면에 '이맘때' 아이콘을 만들어, 주소창 없이 앱처럼 바로 열리게 합니다(사용자 요청). 앱 이름은 '이맘때 풍경', 홈 화면 아이콘 이름은 '이맘때'입니다(D6).

## 왜
- 주소창과 아래 도구 막대가 사라져 화면이 위아래로 넓어집니다. 위아래가 짧게 느껴지는 문제를 푸는 방법이기도 합니다.
- 다음에 다시 열 때 카카오톡 대화방을 뒤질 필요가 없습니다.
- **알파 지인은 카톡 링크로 들어옵니다.** 카톡 안 화면에서는 홈 화면에 둘 수 없고, 거기서 저장한 곳은 크롬·설치한 앱으로 넘어가지 않습니다(저장이 브라우저마다 따로 — PRD 3-2장 '알려진 한계'). 그래서 안내 시점을 바꿨습니다(D33, 10/4 사용자 — PRD 3-6장).

## 휴대폰마다 다른 점
| 어디서 열었나 | 할 수 있는 것 |
|---|---|
| 안드로이드 크롬 | 우리 버튼을 누르면 휴대폰의 '설치' 창이 바로 뜹니다. 창이 아직 준비되지 않았으면 메뉴로 하는 그림 안내(⋮ → 홈 화면에 추가 → 설치) |
| 안드로이드 삼성 인터넷 | 27판부터 설치 창 신호가 오지 않는다는 보고가 있어 **메뉴로 하는 그림 안내**(≡ → 현재 페이지 추가 → 홈 화면) |
| 아이폰 사파리 | 자동 설치 창이 없습니다. 그림 안내(⋯ → 공유 → 홈 화면에 추가 → 추가). 아이폰은 홈 화면 앱과 사파리의 저장이 따로입니다 |
| **카카오톡 안에서 연 화면** | 설치할 수 없습니다. 첫 화면 맨 위 띠로 크롬(아이폰은 사파리)으로 넘기고, 넘어가지 않으면 카톡 메뉴 그림 안내(⋮ → 다른 브라우저로 열기). 넘기는 방법과 저장한 곳 함께 넘기기는 실기기 확인(PR #43 확인 페이지) |
| 이미 홈 화면 아이콘으로 연 경우 | 버튼과 안내를 숨깁니다 |

## 언제, 어디서 안내하나 (D33 · 10/4 사용자)
| 어디서 열었나 | 언제 | 무엇을 |
|---|---|---|
| 카톡 안(안드로이드·아이폰) | **첫 방문부터** | 첫 화면 맨 위 얇은 띠 '크롬으로 열면 앱처럼 쓸 수 있어요 / 크롬으로 열기 ›'(아이폰은 사파리). 화면을 덮지 않고, ✕로 닫을 수 있음 |
| 크롬·삼성 인터넷(설치 전) | **처음 [저장]을 누른 직후** 한 번 | 저장 안내 줄 대신 판: 앱 아이콘 + '저장했어요' + '홈 화면에 두면 저장한 곳을 바로 열 수 있어요' [홈 화면에 두기] [괜찮아요]. 닫으면 다시 안 뜸 |
| 늘 | — | 첫 화면 맨 아래 · 저장한 곳 맨 아래 '홈 화면에 두기' 카드(앱 아이콘 + '앱처럼 바로 열려요.') |
| 홈 화면 아이콘으로 엶 | — | 띠·판·카드를 모두 숨김 |

- 처음 방문 때 크롬에서는 묻지 않습니다. 저장할 때가 이유가 가장 분명한 때입니다.
- 화면 모양과 글자: `docs/design-guide.md` 11장(모양)·10-6(글자), 디자인 캔버스 ⑤줄.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F5-AC1 | 앱에 이름('이맘때 풍경', 짧은 이름 '이맘때'), 아이콘(192·512px, 안드로이드용 maskable 포함, 아이폰 180px), 시작 주소, 전체 화면 표시 설정이 들어 있습니다(웹 앱 매니페스트). 아이콘은 `public/brand/`의 '나'안입니다. | 데이터 규칙 |
| F5-AC2 | 안드로이드 크롬에서 버튼을 누르면 설치 창이 뜹니다. 이를 위해 작은 서비스 워커를 둡니다. 크롬은 자동 설치 창을 띄우려면 아직 이것이 필요합니다. 설치 창이 준비되지 않았으면 크롬 그림 안내가 뜹니다. | 실기기 |
| F5-AC3 | 아이폰 사파리에서 버튼을 누르면 '⋯ → 공유 → 홈 화면에 추가 → 추가' 그림 안내가 나옵니다. | 화면·실기기 |
| F5-AC4 | **카카오톡 안에서 열면 첫 방문부터 첫 화면 맨 위에 '크롬으로 열기' 띠가 보입니다(아이폰은 사파리).** 띠를 누르면 바깥 브라우저로 넘어가고, 넘어가지 못하면(약 2초 뒤에도 그 화면) '크롬이 열리지 않았나요?' 그림 안내가 나옵니다. 카톡 안에서 '홈 화면에 두기' 카드를 눌러도 같은 안내가 나옵니다. | 화면·실기기 |
| F5-AC5 | 홈 화면 아이콘으로 열면 주소창이 없고, 띠·판·'홈 화면에 두기' 카드가 보이지 않습니다. | 화면·실기기 |
| F5-AC6 | **크롬·삼성 인터넷에서(설치 전) 처음 [저장]을 누른 직후 한 번만** 홈 화면에 두기 판이 저장 안내 줄 대신 나옵니다. [괜찮아요]나 덮개로 닫으면 이 브라우저에서는 다시 나오지 않습니다. 카톡 띠도 ✕로 닫으면 다시 나오지 않습니다. 아이폰에서는 이 판을 띄우지 않습니다. | 단위·화면 |
| F5-AC7 | 설치 창이 없을 때의 그림 안내가 브라우저별(크롬·삼성 인터넷·아이폰 사파리·카톡)로 나옵니다. 판이 화면보다 길면 판 안에서 스크롤되고, 320px 폭에서 가로로 넘치지 않습니다. | 화면 |
| F5-AC8 | 크롬에서 설치를 마치면 "홈 화면에 '이맘때'를 두었어요" 안내 줄이 몇 초 뜹니다. | 화면·실기기 |

## 필요한 것
- **앱 아이콘:** ✅ 10/4 사용자가 '나'안(달력 한 장 + 키 다른 두 봉우리)으로 정함 — `public/brand/`, 원본은 `design/app-icon/`.
- **실기기 확인:** 카톡 → 크롬 넘기기, 저장한 곳 함께 넘기기, 크롬·삼성 인터넷 설치 창(PR #43 확인 페이지). 결과에 따라 그림 안내의 메뉴 이름·자리를 맞춥니다(design-guide 10-6).
- 들어갈 단계: 알파 전(D2 — F1~F5를 모두 만든 뒤 알파).
