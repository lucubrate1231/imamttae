# F5. 홈 화면에 추가 (앱처럼 쓰기)

**한 줄:** 휴대폰 홈 화면에 '이맘때' 아이콘을 만들어, 주소창 없이 앱처럼 바로 열리게 합니다(사용자 요청). 앱 이름은 '이맘때 풍경', 홈 화면 아이콘 이름은 '이맘때'입니다(D6).

## 왜
- 주소창과 아래 도구 막대가 사라져 화면이 위아래로 넓어집니다. 위아래가 짧게 느껴지는 문제를 푸는 방법이기도 합니다.
- 다음에 다시 열 때 카카오톡 대화방을 뒤질 필요가 없습니다.
- **알파 지인은 카톡 링크로 들어옵니다.** 카톡 안 화면에서는 홈 화면에 둘 수 없고, 거기서 저장한 곳은 크롬·설치한 앱으로 넘어가지 않습니다(저장이 브라우저마다 따로 — PRD 3-2장 '알려진 한계'). 그래서 안내 시점을 바꿨습니다(D33, 10/4 사용자 — PRD 3-6장).
- **안드로이드 크롬·삼성 인터넷도 첫 방문부터 띠로 안내합니다(D37, 10/5 사용자).** 아이폰은 카톡에서 열면 첫 화면부터 '사파리로 열기' 띠가 보여 자연스러운데, 안드로이드 크롬·삼성 인터넷은 [저장]을 눌러야만 안내가 떴습니다. 카톡 링크가 설정에 따라 크롬으로 바로 열리기도 해서, 그런 사람은 저장하기 전에는 설치 안내를 못 봤어요.
- **안드로이드·PC는 '앱으로 설치하기', 아이폰은 '홈 화면에 두기'로 말합니다(10/6, 안드로이드 지인 실기기).** 설치는 잘 됐지만(띠 → 크롬 '앱 설치' → 알림 '설치됨' → 알림으로 열림) 지인은 '홈 화면 설치는 안 되고 앱 설치만 된다'고 느꼈습니다. ① 우리는 '홈 화면에 두기'라고 하는데 크롬 화면에는 '앱 설치'만 나왔고, ② 갤럭시는 설치해도 홈 화면에 아이콘이 저절로 안 생길 수 있어(앱 목록에만) 아이콘을 찾으려고 위젯 목록을 뒤졌습니다. 그래서 크롬이 쓰는 말에 맞추고, 설치를 마친 직후 앱 목록에서 홈 화면에 꺼내는 법을 한 번 알려 줍니다.

## 휴대폰마다 다른 점
| 어디서 열었나 | 할 수 있는 것 |
|---|---|
| 안드로이드 크롬 | 첫 방문부터 첫 화면 맨 위 '앱으로 설치하기' 띠(D37 · 10/6). 띠나 우리 버튼을 누르면 크롬의 '앱 설치' 창이 바로 뜹니다. 창이 아직 준비되지 않았으면 메뉴로 하는 그림 안내(⋮ → 앱 설치 → 설치, '앱 설치'는 '홈 화면에 추가'로 보일 수도). **갤럭시는 설치해도 아이콘이 앱 목록에만 생길 수 있어** 설치 직후 꺼내는 법을 알려 줍니다 |
| 안드로이드 삼성 인터넷 | 첫 방문부터 같은 띠(D37 · 10/6). 27판부터 설치 창 신호가 오지 않는다는 보고가 있어, 띠나 버튼을 누르면 **메뉴로 하는 그림 안내**(≡ → 현재 페이지 추가 → 홈 화면) |
| 아이폰 사파리 | 자동 설치 창이 없습니다. 그림 안내(공유 → 홈 화면에 추가 → 추가). 공유 버튼은 판·설정마다 자리가 달라 **모양으로** 안내하고, 안 보이면 주소창 옆 ⋯을 먼저 누르게 합니다(10/5 실기기). 아이폰은 홈 화면 앱과 사파리의 저장이 따로입니다 |
| **카카오톡 안에서 연 화면** | 설치할 수 없습니다. 첫 화면 맨 위 띠로 크롬(아이폰은 사파리)으로 넘기고, 넘어가지 않으면 카톡 메뉴 그림 안내(⋮ → 다른 브라우저로 열기). 넘기는 방법과 저장한 곳 함께 넘기기는 실기기 확인(PR #43 확인 페이지) |
| **밴드·네이버 앱 등 다른 앱 안 화면**(10/6, D45) | 카톡 안과 같습니다 — 설치할 수 없고 저장이 앱 안에 갇힙니다. 같은 띠로 크롬(아이폰은 사파리)으로 넘기고, 넘어가지 않으면 '{앱} 메뉴로 열 수 있어요' 그림 안내(공통안: ⋮/⋯ → 다른 브라우저로 열기). 비공개 베타 2차(밴드·산악회·동창)는 밴드 앱 안에서 엽니다. 넘기는 방법·메뉴 이름은 Claude Code 실기기 확인 |
| 이미 홈 화면 아이콘으로 연 경우 | 버튼과 안내를 숨깁니다 |

## 언제, 어디서 안내하나 (D33 · 10/4 → D37 · 10/5 사용자 · 10/6 안드로이드 말)
| 어디서 열었나 | 언제 | 무엇을 |
|---|---|---|
| 앱 안 화면 — 카톡·밴드·네이버 앱 등(안드로이드·아이폰) | **첫 방문부터** | 첫 화면 맨 위 얇은 띠 '크롬으로 열면 앱처럼 쓸 수 있어요 / 크롬으로 열기 ›'(아이폰은 사파리). 화면을 덮지 않고, ✕로 닫을 수 있음 |
| 크롬·삼성 인터넷(안드로이드 휴대폰, 설치 전) | **첫 방문부터** | 첫 화면 맨 위 얇은 띠 '앱으로 설치하면 바로 열 수 있어요 / 앱으로 설치하기 ›'(10/6) — 카톡 띠와 같은 모양(하늘색 + 앱 아이콘). 누르면 크롬은 설치 창, 없으면(삼성 인터넷 포함) 그림 안내. 화면을 덮지 않고, **✕로만 닫힘** |
| 크롬·삼성 인터넷(설치 전) | **처음 [저장]을 누른 직후** 한 번 — 띠를 ✕로 닫지 않았고 설치 창에서 [취소]한 적이 없을 때만 | 저장 안내 줄 대신 판: 앱 아이콘 + '저장했어요' + '앱으로 설치하면 저장한 곳을 바로 열 수 있어요' [앱으로 설치하기] [괜찮아요]. 닫으면 다시 안 뜸 |
| PC 크롬 | — | 띠 없음. 저장 직후 판·카드는 지금처럼. 설치를 마치면 안내 줄 "'이맘때'를 앱으로 설치했어요" |
| 늘 | — | 첫 화면 맨 아래 · 저장한 곳 맨 아래 카드(앱 아이콘 + '앱처럼 바로 열려요.') — 안드로이드·PC는 '앱으로 설치하기', 아이폰은 '홈 화면에 두기' |
| 홈 화면 아이콘으로 엶 | — | 띠·판·카드를 모두 숨김 |
| 설치를 마침(안드로이드) | 설치 끝 신호(`appinstalled`) — 한 번 | **설치 직후 판:** 앱 아이콘 + '설치됐어요' + "휴대폰 앱 목록에 '이맘때'가 생겼어요" + '홈 화면에 아이콘이 없으면' ① 앱 목록에서 '이맘때'를 길게 누르세요(앱 목록은 홈 화면을 위로 밀면 나와요. 위젯 목록에는 없어요.) ② '홈 화면에 추가'를 누르세요 [알겠어요]. 맨 위 띠가 사라짐 |

- 띠는 묻는 창이 아니라 화면을 가리지 않는 안내라서 첫 방문부터 둡니다(D37). 저장 직후 판은 이유가 가장 분명한 때에 한 번 더 권하는 것이라, **한 번 거절한 사람(띠 ✕, 설치 창 [취소])에게는 다시 묻지 않습니다.**
- 띠는 ✕로만 닫힙니다(10/5 사용자). 설치 창 [취소]·판 [괜찮아요]·그림 안내 [알겠어요]로는 닫히지 않아, 실수로 취소한 사람도 다시 할 수 있습니다.
- 화면 모양과 글자: `docs/design-guide.md` 11장(모양)·10-6(글자), 디자인 캔버스 ⑤줄.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F5-AC1 | 앱에 이름('이맘때 풍경', 짧은 이름 '이맘때'), 아이콘(192·512px, 안드로이드용 maskable 포함, 아이폰 180px), 시작 주소, 전체 화면 표시 설정이 들어 있습니다(웹 앱 매니페스트). 아이콘은 `public/brand/`의 '나'안입니다. | 데이터 규칙 |
| F5-AC2 | 안드로이드 크롬에서 맨 위 띠나 버튼을 누르면 크롬의 '앱 설치' 창이 뜹니다. 이를 위해 작은 서비스 워커를 둡니다. 크롬은 자동 설치 창을 띄우려면 아직 이것이 필요합니다. 설치 창이 준비되지 않았으면 크롬 그림 안내('앱으로 설치하는 방법' — ② '앱 설치', 보충 "'홈 화면에 추가'로 보일 수도 있어요")가 뜹니다. | 실기기 |
| F5-AC3 | 아이폰 사파리에서 버튼을 누르면 '공유 → 홈 화면에 추가 → 추가' 그림 안내가 나옵니다. 1단계는 공유 버튼의 **자리가 아니라 모양**(공유 아이콘)으로 안내하고 '안 보이면 주소창 옆 [⋯] 버튼을 먼저 누르세요'를 덧붙입니다. 3단계 보충은 "'웹 앱으로 열기'가 보이면 켠 채로 두세요"입니다(10/5 사용자 실기기 — design-guide 10-6·11-4). | 화면·실기기 |
| F5-AC4 | **카카오톡 안에서 열면 첫 방문부터 첫 화면 맨 위에 '크롬으로 열기' 띠가 보입니다(아이폰은 사파리).** 띠를 누르면 바깥 브라우저로 넘어가고, 넘어가지 못하면(약 2초 뒤에도 그 화면) '크롬이 열리지 않았나요?' 그림 안내가 나옵니다. 카톡 안에서 맨 아래 카드를 눌러도 같은 안내가 나옵니다.<br>**밴드·네이버 앱 등 다른 앱 안 화면에서도 같은 띠가 보입니다(10/6, D45).** 띠 글자는 같고, 넘어가지 못하면 나오는 판의 설명만 '밴드 메뉴로 열 수 있어요.' · '네이버 앱 메뉴로 열 수 있어요.' · '이 앱의 메뉴로 열 수 있어요.'로 다릅니다(순서는 공통안 — design-guide 11-2·10-6). | 화면·실기기 |
| F5-AC5 | 홈 화면 아이콘으로 열면 주소창이 없고, 띠·판·맨 아래 카드가 보이지 않습니다. | 화면·실기기 |
| F5-AC6 | **안드로이드 휴대폰의 크롬·삼성 인터넷에서(설치 전) 첫 방문부터 첫 화면 맨 위에 '앱으로 설치하기' 띠가 보입니다(D37).** 글자는 '앱으로 설치하면 바로 열 수 있어요 / 앱으로 설치하기 ›'(10/6), 모양은 카톡 띠와 같습니다. 맨 아래 카드와 저장 직후 판 버튼도 '앱으로 설치하기'입니다(아이폰은 '홈 화면에 두기'). 띠를 누르면 크롬은 설치 창, 설치 창이 없거나 삼성 인터넷이면 그 브라우저 그림 안내가 나옵니다. **띠는 ✕로만 닫히고**, 닫으면 이 브라우저에서는 다시 나오지 않습니다(설치 창 [취소]·판 [괜찮아요]로는 닫히지 않음). 설치를 마치면 띠가 사라집니다. PC 크롬에는 띠가 없습니다.<br>**처음 [저장]을 누른 직후 판은 한 번만**, 띠를 ✕로 닫지 않았고 설치 창에서 [취소]한 적이 없을 때만 저장 안내 줄 대신 나옵니다. [괜찮아요]나 덮개로 닫으면 다시 나오지 않습니다. 카톡 띠도 ✕로 닫으면 다시 나오지 않습니다. 아이폰에서는 이 판을 띄우지 않습니다. | 단위·화면·실기기 |
| F5-AC7 | 설치 창이 없을 때의 그림 안내가 브라우저별(크롬·삼성 인터넷·아이폰 사파리·카톡)로 나옵니다. 판이 화면보다 길면 판 안에서 스크롤되고, 320px 폭에서 가로로 넘치지 않습니다. | 화면 |
| F5-AC8 | **안드로이드에서 설치를 마치면(`appinstalled`) 설치 직후 판이 한 번 뜹니다** — "휴대폰 앱 목록에 '이맘때'가 생겼어요"와, 홈 화면에 없을 때 앱 목록에서 '이맘때'를 길게 눌러 '홈 화면에 추가'하는 두 단계(10/6 실기기 — 갤럭시는 아이콘이 앱 목록에만 생길 수 있음). 맨 위 띠는 사라집니다. PC 크롬은 안내 줄 "'이맘때'를 앱으로 설치했어요"가 몇 초 뜹니다. 옛 "홈 화면에 '이맘때'를 두었어요"는 쓰지 않습니다. | 단위·화면·실기기 |

## 필요한 것
- **앱 아이콘:** ✅ 10/4 사용자가 '나'안(달력 한 장 + 키 다른 두 봉우리)으로 정함 — `public/brand/`, 원본은 `design/app-icon/`.
- **실기기 확인:** 카톡 → 크롬 넘기기, 저장한 곳 함께 넘기기, 크롬·삼성 인터넷 설치 창(PR #43 확인 페이지). **D37 띠가 미리보기에 올라간 뒤** 안드로이드 지인에게 함께 확인합니다(카톡 → 크롬으로 넘어온 뒤 띠가 보이는지, 띠 → 설치 창). 결과에 따라 그림 안내의 메뉴 이름·자리를 맞춥니다(design-guide 10-6).
  - **10/6 안드로이드 지인(크롬):** 띠 → '앱 설치' → 알림 '설치됨' → 알림으로 열림까지 잘 됨. 말이 달라 헷갈림, 아이콘이 홈 화면에 안 생김(앱 목록에만) → 이 문서·design-guide를 고침. 고친 뒤 다시 볼 것: 설치 직후 판이 뜨는지, 갤럭시 앱 목록 길게 누르기 메뉴에 '홈 화면에 추가'가 그 이름으로 있는지, 삼성 인터넷 메뉴 순서.
- 들어갈 단계: 알파 전(D2 — F1~F5를 모두 만든 뒤 알파).
