# F5. 홈 화면에 추가 (앱처럼 쓰기)

**한 줄:** 휴대폰 홈 화면에 '이맘때' 아이콘을 만들어, 주소창 없이 앱처럼 바로 열리게 합니다(사용자 요청).

## 왜
- 주소창과 아래 도구 막대가 사라져 화면이 위아래로 넓어집니다. 위아래가 짧게 느껴지는 문제를 푸는 방법이기도 합니다.
- 다음에 다시 열 때 카카오톡 대화방을 뒤질 필요가 없습니다.

## 휴대폰마다 다른 점
| 어디서 열었나 | 할 수 있는 것 |
|---|---|
| 안드로이드 크롬·삼성 인터넷 | 우리 버튼을 누르면 휴대폰의 '설치' 창이 바로 뜹니다 |
| 아이폰 사파리 | 자동 설치 창이 없습니다. '공유 버튼 → 홈 화면에 추가'를 그림으로 안내합니다 |
| **카카오톡 안에서 연 화면** | 설치할 수 없습니다. "다른 브라우저로 열기"를 먼저 안내합니다 *(카카오톡이 바로 바깥 브라우저로 여는 방법이 있는지는 실기기로 확인 필요)* |
| 이미 홈 화면 아이콘으로 연 경우 | 버튼과 안내를 숨깁니다 |

## 어디에 둘까 (제안)
1. **수첩 화면 맨 아래:** "홈 화면에 추가" 버튼을 늘 둡니다. 수첩이 '내 화면' 역할이라서입니다.
2. **두 번째로 방문했을 때 한 번만:** 첫 화면 사진 카드 아래에 작은 안내 카드를 보여 줍니다. 문구는 "홈 화면에 추가하면 앱처럼 바로 열려요 [추가하기] [괜찮아요]"이고, 닫으면 다시 뜨지 않습니다.
   - 처음 방문 때는 띄우지 않습니다. 앱을 써 보기도 전에 묻지 않기 위해서입니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F5-AC1 | 앱에 이름(정식 이름 '이맘때 풍경', 홈 화면 아이콘 이름 '이맘때', 10/4 결정 D6), 아이콘(192·512px), 시작 주소, 전체 화면 표시 설정이 들어 있습니다(웹 앱 매니페스트). | 데이터 규칙 |
| F5-AC2 | 안드로이드 크롬에서 버튼을 누르면 설치 창이 뜹니다. 이를 위해 작은 서비스 워커를 둡니다. 크롬은 설치 창을 띄우려면 아직 이것이 필요합니다. | 실기기 |
| F5-AC3 | 아이폰 사파리에서 버튼을 누르면 '공유 → 홈 화면에 추가' 안내 그림이 나옵니다. | 화면·실기기 |
| F5-AC4 | 카카오톡 안에서 버튼을 누르면 '다른 브라우저로 열기' 안내가 나옵니다. | 화면·실기기 |
| F5-AC5 | 홈 화면 아이콘으로 열면 주소창이 없고, 버튼과 안내 카드가 보이지 않습니다. | 화면·실기기 |
| F5-AC6 | 안내 카드는 두 번째 방문에 한 번만 나오고, 닫으면 이 휴대폰에서는 다시 나오지 않습니다. | 단위·화면 |
