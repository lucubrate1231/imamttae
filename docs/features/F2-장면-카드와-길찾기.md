# F2. 장면 카드와 길찾기

**한 줄:** 핀을 누르면 그 장면의 사진과 작가의 글 한 대목이 나오고, 버튼 하나로 주차장까지 길찾기가 열립니다.

> **10/4 기획 결정 반영**(PRD 3-3장): 꼬리표는 오늘 기준, 구역 순서, 길찾기 티맵 기본, 공유는 알파에 넣음(D1), 앱 이름 '이맘때 풍경'(D6).

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F2-AC1 | 이야기 핀이나 카드를 누르면 **장면 상세**가 올라오고, 주소는 `#/scene/…`이 됩니다. 뒤로 버튼·휴대폰 뒤로 가기로 닫힙니다. 주소로 바로 열었으면 뒤로 버튼은 첫 화면으로 갑니다. 아래로 쓸어내려 닫기는 나중에 따로 넣습니다(10/3 사용자 결정). | 흐름 |
| F2-AC2 | 상세에는 **풍경 사진**(옆으로 넘겨 최대 8장), 꼬리표, 장면 이름, 지역, 한 줄 소개, **추천 시기**, **작가 글 한 대목**, "브런치에서 전체 이야기 읽기" 링크가 있습니다. **가는 곳 칸은 두지 않습니다**(제목과 겹침). 구역 순서는 **① 꼬리표·제목·지역·한 줄 소개 → ② 추천 시기 → ③ 작가의 한마디 → ④ 브런치 전체 이야기**입니다(10/4 결정). 가로선 없이 위아래 여백(40px)으로 나눕니다. **꼬리표는 오늘(한국 날짜) 기준**입니다(10/4 결정): 오늘이 추천 시기 안이면 **[지금 제철]**, 일 년 내내 볼 수 있는 곳은 **[일 년 내내]**(기획 제안, 화면에서 확인), 그 밖은 풍경 종류만 둡니다. 첫 화면에서 다른 달을 골라 둬도 기준은 오늘입니다. '작가 부부 방문' 꼬리표는 두지 않습니다. 제목 위계는 제목(명조 28 굵게) → 지역(16 연한 회색, 제목에 붙임) → 한 줄 소개(18 보통 굵기, 위로 띄움)입니다. 작가의 한마디는 작은 제목 + 명조 고운바탕 굵게 + 계절색을 옅게 섞은 왼쪽 세로선이고, 아래에는 **다녀온 날짜만** 작게 적습니다. 사진 위 크레딧('사진·글 이상호'와 서명 자리)은 작게 둡니다. | 화면 |
| F2-AC2b | 사진 위에는 **뒤로 버튼, 넘김 화살표, 크레딧만** 둡니다. 크레딧은 **'사진 이상호' + 작가 손글씨 서명**입니다(10/5 사용자, 옛 '사진·글 이상호'). 뒤로 버튼은 **흰 동그라미**, 넘김 화살표는 **검정 반투명의 세로로 긴 둥근 사각형**으로 모양과 색을 달리합니다(보이는 크기는 작아도 누르는 범위는 48px 이상). 사진 아래 **점**으로 장 수를 알려 주고, 첫 장에서는 왼쪽, 끝 장에서는 오른쪽 화살표를 숨깁니다. 버튼은 상세에 들어오자마자 뜨지 않고 **사진이 뜨고 1초 뒤에 서서히** 나타납니다. **사진을 넘기면(화살표·밀기) 버튼이 숨었다가 약 0.5초 안에 다시 다 보입니다**(5차 코멘트, 6차 2배 빠르게, 7차 0.5초 — 화살표는 누르고 0.25초 뒤, 밀기는 멈추고 0.1초 뒤부터 0.25초 동안 서서히). 그 전에 사람이 위아래로 스크롤하거나 사진을 톡 누르면 바로 서서히 나타나고, 사진이 늦게 떠도 3.5초 안에는 나타납니다(10/3 4차 코멘트: 2초 → 1초, 상세를 다시 열 때 바로 뜨던 문제 고침). **상세 화면은 옆으로 밀리지 않습니다**(가로 넘침 없음). | 화면·흐름 |
| F2-AC2c | 화면 아래에 **붙박이 막대**를 둡니다: **가고 싶어요 · 공유 · 길찾기(티맵)**. 가고 싶어요를 누르면 '담았어요'로 바뀌고 수첩의 '가고 싶은 곳'에 들어갑니다. 다시 누르면 뺍니다. 이 휴대폰에만 저장합니다(저장은 Codex 일 2 `docs/tasks/codex-2-가고싶어요-저장.md`, 그전까지는 화면을 닫으면 사라지는 임시 저장). | 단위·화면 |
| F2-AC2d | (10/3 사용자 확정) 장면 상세의 **지금 사진만** 14초 동안 한 번 아주 천천히 움직입니다. 옆으로 긴 사진은 좌우로 밀고, 그 밖은 6% 확대하며, 사진의 초점에서 멈춥니다. 사진을 넘기면 새로 시작하고, '동작 줄이기' 설정이면 움직이지 않습니다. 점검용으로 `?motion=0`이면 멈춥니다(`docs/design-guide.md` 6-1). | 단위·화면 |
| F2-AC3 | **작가 글 대목은 브런치 원문 그대로**입니다(한 글자라도 다르면 자동 검사가 막습니다). 대목 아래에는 다녀온 날짜만 적습니다(10/3 결정으로 '— 이상호, ○번째 여행'은 뺌, F2-AC2). | 데이터 규칙 |
| F2-AC4 | 작가가 아직 확인하지 않은 항목(가장 좋은 때, 한 줄 소개, 가는 곳)에는 작은 **'초안'** 꼬리표가 붙습니다. | 화면 |
| F2-AC5 | **길찾기 기본은 티맵**입니다(10/4 결정). 버튼 글자는 **'길찾기(티맵)'**이고, 누르면 티맵이 좌표(주차장·입구)로 바로 열립니다. 본문 맨 아래 작은 **'다른 앱으로 길찾기'**로 네이버지도·카카오맵을 고르면 이 휴대폰에 기억하고 다음부터 그 앱으로 엽니다(버튼 글자도 바뀜). 티맵이 열리지 않으면(1.5초 뒤에도 화면이 그대로) **'티맵 설치 / 네이버지도 / 카카오맵'** 안내가 올라옵니다. **티맵 실제 휴대폰 확인은 알파 전 필수**입니다(안드로이드·아이폰). | 단위·화면·실기기 |
| F2-AC6 | 길찾기는 **이름이 아니라 좌표**로 열고, 목적지는 풍경 지점이 아니라 **주차장·입구 좌표**입니다(화면에 '가는 곳'을 따로 적지는 않음). | 단위·데이터 규칙(장면–가는 곳 15km 안) |
| F2-AC7 | PC에서는 카카오맵 웹으로 엽니다. 티맵·네이버지도 앱 주소는 PC에서 열리지 않기 때문입니다. | 단위 |
| F2-AC8 | **준비 중 핀**을 누르면 이름, 다녀온 날, "작가가 글을 다듬고 있어요. 브런치에 발행되면 여기에 이야기가 채워져요"만 나옵니다. 사진, 본문, 길찾기는 없습니다. | 화면·데이터 규칙 |
| F2-AC9 | **공유** 버튼을 누르면 휴대폰 공유 창(카카오톡 등)이 열립니다. 공유 창이 없는 브라우저에서는 주소를 복사하고 "주소를 복사했어요"라고 알립니다. 받은 사람은 같은 장면을 봅니다. 보내는 글은 '{장면 이름}, "이맘때 풍경"에서 봤어요. 한번 보실래요? {공유 주소}'입니다(10/8 새벽 — 높임말, 주소는 한 칸 띄워 같은 글에 붙여 아이폰 카톡의 빈 줄을 없앰)(10/8 — 앱이 넣은 말인 걸 알게 서비스 이름을 큰따옴표로)(마케팅 M11, 10/8 프프 — D58 ③을 바꿈: 받는 날 철이 안 맞을 수 있어 추천 시기를 뺌). 카카오톡 미리보기 카드는 제목 "이맘때 풍경 — 지금 가면 딱 좋은 곳", 설명 "산악인 작가가 아내와 직접 다녀온 곳만 모았어요"(D58). **정함(10/4, D1): 알파에 넣습니다.** **장면별 카톡 미리보기(D63, 10/7 — 백로그 D15를 당김):** [공유]·[카톡으로 알리기]는 장면 공유 페이지 `https://imamttae.site/s/<장면 번호>/?from=share`(D64, 미리보기는 `/next/s/…`)를 보냅니다. 그 페이지에는 그 장면의 카드 정보가 있고(제목 "{장면 이름} — 이맘때 풍경", 설명 "{지역} · 작가가 아내와 다녀온 곳"(M11 — 아이폰에서 앞이 길어 잘려 추천 시기·'직접'을 뺌), 그림은 그 장면 첫 사진을 1200×630으로 가운데 자른 것 · 다음 후보로 앱 공통 그림), 열면 바로 앱의 그 장면으로 넘어갑니다. 빌드 때 보이는 장면마다 자동으로 만들고(숨긴 장면 빼고), 없어진 장면 주소는 앱 첫 화면으로 갑니다. 검색 막기(noindex)는 정식 출시 전까지. 응모작이 수상하면 장면 데이터(사진·대목)를 바꾸면 다음 배포에 공유 페이지도 같이 바뀌고, 카카오 공유 디버거에서 그 장면 주소를 캐시 초기화합니다(`src/domain/sharePage.ts`). | 흐름 |
| F2-AC10 | 사진을 못 불러오면 빈 회색 자리와 "사진은 브런치에서 볼 수 있어요"를 보여 줍니다. 사진은 화면에 보일 때만 불러옵니다. | 화면 |
| F2-AC12 | **추천 시기**는 날짜로 보여 줍니다(예: 추천 시기 10월 말~11월 초). 꽃·단풍·억새·눈 장면에는 추천 시기 상자 아래 **찾아보기 카드**(D66 10/8 — 제목 글자 '떠나기 전에 확인하세요'는 지움, 읽기 이름 '찾아보기')에 **시기 줄**("단풍 드는 때는 해마다 1~2주씩 달라져요" + **올해 단풍지도 찾아보기**, 줄 전체가 링크)을 둡니다(10/5 사용자 — 옛: 같은 상자 안 안내 + 링크, design-guide 6장). 링크는 **구글 검색**이고 검색어 **맨 끝에 '시기'**를 붙입니다(D40, 10/5 — 네이버는 결과 앞 광고가 많고, 구글은 맨 위 AI 개요가 바로 요약). **꽃·단풍은 장소가 아니라 '누른 해 + ○○지도 + 시기'**(단풍 → '2026 단풍지도 시기', 벚꽃 → '2026 벚꽃지도 시기', 그 밖의 꽃 → '2026 꽃지도 시기', 글자 '올해 단풍지도 찾아보기 ›'), **억새·갈대·눈은 '장소 이름(풍경 말 빼고) + 누른 해 + 억새/갈대/눈 + 시기'**(예: '원동습지 2026 갈대 시기', '발왕산 2026 눈 시기'). 갈대 장면은 종류가 '억새·갈대'여도 '갈대'로 찾습니다(`src/domain/timingNotice.ts`). | 단위·화면 |
| F2-AC13 | **모든 장면**에 사진 바로 아래 캡션 **"8월에 찍은 사진"**으로 사진의 계절을 밝힙니다(10/4 결정 D30, 자리·글 10/5 사용자 — 왼쪽 캡션·오른쪽 사진 점이 한 줄, 배경 없이 글자만). **철이 아니면** 추천 시기 칸 맨 위에 **"지금은 철이 아니에요 · N월부터"**(추천 시기의 시작 달)를 둡니다. | 화면 |
| F2-AC14 | **입장료·운영 시간(D4, 10/5 사용자):** 데이터 `checkAdmission`이 켜진 장면(민간 정원·유료 수목원 등)에는 **'떠나기 전에 확인하세요' 카드**에 **입장료 줄**("입장료와 운영 시간은 미리 확인하세요" + **입장료·운영 시간 찾아보기** — 구글 검색 '{장소 이름} 입장료 운영시간', 장소 이름은 장면 이름에서 풍경 말을 뺀 것(예: '천리포수목원 봄 연못' → '천리포수목원', D40))을 둡니다. 시기 줄이 있으면 그 아래, 없으면(일 년 내내 장면 등) 이 줄만 있는 카드입니다. 금액·시간은 적지 않습니다(보는 때에 따라 틀려짐). 카드·목록에는 두지 않습니다. | 단위·화면 |
| F2-AC15 | **본문 끝 '이곳 정보가 달라졌나요?'(10/6 사용자, D46):** 안전 안내 아래에(그 뒤 맨 끝이 '다른 앱으로 길찾기' — D67, 10/8) '이곳 정보가 달라졌나요? · 주차·길·입장 등 알려 주시면 고칠게요 ›' 줄이 있습니다. 누르면 의견 폼이 새 창으로 열리고 '어느 곳' 칸에 이 장면 이름이 미리 들어갑니다(공통 C-10, design-guide 6장·12-1). 아래 붙박이 막대에 가리지 않습니다. | 화면 |
| F2-AC16 | **안전 안내(10/7, 공통 C-12):** 모든 장면의 본문 끝, '이곳 정보가 달라졌나요?' 줄 바로 위에 ⓘ와 '정보는 작가가 다녀온 때를 기준으로 해요. 길·주차·출입 통제는 떠나기 전에 현장 안내를 확인하시고, 날씨와 몸 상태에 맞게 무리하지 마세요.'가 작은 글(15px)로 있습니다. | 화면 |
| F2-AC11 | **공모전 수상 대비:** 응모작 표시가 켜진 글은 스위치 하나로 **링크 카드**(사진 1장, 제목, 다녀온 날, 한 줄 소개, 브런치 링크)로 바뀝니다. | 단위·화면 |
