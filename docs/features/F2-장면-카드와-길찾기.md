# F2. 장면 카드와 길찾기

**한 줄:** 핀을 누르면 그 장면의 사진과 작가의 글 한 대목이 나오고, 버튼 하나로 주차장까지 길찾기가 열립니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F2-AC1 | 이야기 핀을 누르면 아래에서 **장면 카드**가 올라오고, 주소는 `#/scene/…`이 됩니다. 뒤로 가기·닫기 버튼·아래로 쓸어내리기로 닫힙니다. | 흐름 |
| F2-AC2 | 카드에는 **풍경 사진**(옆으로 넘겨 최대 8장), 장면 이름, 지역, 명장면 꼬리표, **다녀온 날**, **가장 좋은 때**, 한 줄 소개, **작가 글 한 대목**, "전체 이야기는 브런치에서" 링크, **길찾기** 버튼이 있습니다. | 화면 |
| F2-AC3 | **작가 글 대목은 브런치 원문 그대로**입니다(한 글자라도 다르면 자동 검사가 막습니다). 대목 아래에 "— 이상호, ○번째 여행"이라고 출처를 적습니다. | 데이터 규칙 |
| F2-AC4 | 작가가 아직 확인하지 않은 항목(가장 좋은 때, 한 줄 소개, 가는 곳)에는 작은 **'초안'** 꼬리표가 붙습니다. | 화면 |
| F2-AC5 | 길찾기를 처음 누르면 **카카오맵 / 네이버지도** 중에서 고릅니다. 고른 앱은 이 휴대폰에 기억해 두고, 다음부터는 바로 열립니다. 카드 아래 "길찾기 앱 바꾸기"로 다시 고를 수 있습니다. 티맵은 실제 휴대폰에서 확인한 뒤 추가합니다. | 단위·화면·실기기 |
| F2-AC6 | 길찾기는 **이름이 아니라 좌표**로 열고, 목적지는 풍경 지점이 아니라 **가는 곳(주차장·입구)**입니다. 버튼 아래에 "도착: 오색약수터주차장"처럼 적어 줍니다. | 단위·데이터 규칙(장면–가는 곳 15km 안) |
| F2-AC7 | PC에서는 카카오맵 웹으로 엽니다. 네이버지도 앱 주소는 PC에서 열리지 않기 때문입니다. | 단위 |
| F2-AC8 | **준비 중 핀**을 누르면 이름, 다녀온 날, "작가가 글을 다듬고 있어요. 브런치에 발행되면 여기에 이야기가 채워져요"만 나옵니다. 사진, 본문, 길찾기는 없습니다. | 화면·데이터 규칙 |
| F2-AC9 | **공유** 버튼을 누르면 휴대폰 공유 창(카카오톡 등)이 열립니다. 공유 창이 없는 브라우저에서는 주소를 복사하고 "주소를 복사했어요"라고 알립니다. 받은 사람은 같은 카드를 봅니다. *(결정 필요 3)* | 흐름 |
| F2-AC10 | 사진을 못 불러오면 빈 회색 자리와 "사진은 브런치에서 볼 수 있어요"를 보여 줍니다. 사진은 화면에 보일 때만 불러옵니다. | 화면 |
| F2-AC12 | **가장 좋은 때는 계절말을 먼저** 보여 줍니다(예: **늦가을** · 10월 하순~11월 초). 꽃·단풍·억새·눈 장면에는 "해마다 1~2주씩 달라져요. 떠나기 전 올해 ○○ 소식을 확인하세요" 안내와 **올해 소식 찾아보기** 링크를 붙입니다(10/3 사용자 요청). | 단위·화면 |
| F2-AC13 | **다녀온 기록** 장면에는 "작가 부부가 8월에 다녀온 모습이에요. 가장 좋은 때는 늦가을(10월 하순~11월 초)이에요"처럼 사진의 계절을 밝힙니다. | 화면 |
| F2-AC11 | **공모전 수상 대비:** 응모작 표시가 켜진 글은 스위치 하나로 **링크 카드**(사진 1장, 제목, 다녀온 날, 한 줄 소개, 브런치 링크)로 바뀝니다. | 단위·화면 |
