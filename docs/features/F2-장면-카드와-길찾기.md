# F2. 장면 카드와 길찾기

**한 줄:** 핀을 누르면 그 장면의 사진과 작가의 글 한 대목이 나오고, 버튼 하나로 주차장까지 길찾기가 열립니다.

## 완성 기준
| 번호 | 이렇게 되면 완성 | 테스트 |
|---|---|---|
| F2-AC1 | 이야기 핀을 누르면 아래에서 **장면 카드**가 올라오고, 주소는 `#/scene/…`이 됩니다. 뒤로 가기·닫기 버튼·아래로 쓸어내리기로 닫힙니다. | 흐름 |
| F2-AC2 | 카드에는 **풍경 사진**(옆으로 넘겨 최대 8장), 꼬리표(제철이면 '제철' + 풍경 종류, 작가 부부가 다녀온 곳은 풍경 종류만 — '작가 부부 방문' 꼬리표는 상세에 두지 않음, 10/3 6차 코멘트), 장면 이름, 지역, 한 줄 소개, **추천 시기**, **작가 글 한 대목**, "브런치에서 전체 이야기 읽기" 링크가 있습니다. **가는 곳 칸은 두지 않습니다**(제목과 겹침, 10/3 2차 코멘트). 제목 부분은 **위계**를 둡니다 — 제목(명조 28 굵게) → 지역(16 연한 회색, 제목에 붙임) → 한 줄 소개(18 보통 굵기, 위로 띄움)(10/3 4차 코멘트). 본문은 **구역**으로 나누되 가로선 없이 넉넉한 위아래 여백(40px)으로 구분합니다 — ① 꼬리표·제목·지역·한 줄 소개 ② **작가의 한마디**(작은 제목 + 명조 고운바탕 굵게, 계절색을 옅게 섞은 왼쪽 세로선으로 인용 표시) ③ 추천 시기('추천 시기'와 날짜는 한 크기·계절색, 달력 아이콘은 첫 화면 카드에만) + **이럴 때 더 좋아요**(날씨·때 조건, 예: '맑은 날, 눈 온 뒤') ④ 브런치 전체 이야기(10/3 3차 결정). 대목 아래에는 작가 이름·몇 번째 여행 없이 **다녀온 날짜만** 작게 적습니다. 사진 위 크레딧('사진·글 이상호'와 서명 자리)은 작게 둡니다. | 화면 |
| F2-AC2b | 사진 위에는 **뒤로 버튼, 넘김 화살표, 크레딧만** 둡니다. 뒤로 버튼은 **흰 동그라미**, 넘김 화살표는 **검정 반투명의 세로로 긴 둥근 사각형**으로 모양과 색을 달리합니다(보이는 크기는 작아도 누르는 범위는 48px 이상). 사진 아래 **점**으로 장 수를 알려 주고, 첫 장에서는 왼쪽, 끝 장에서는 오른쪽 화살표를 숨깁니다. 버튼은 상세에 들어오자마자 뜨지 않고 **사진이 뜨고 1초 뒤에 서서히** 나타납니다. **사진을 넘기면(화살표·밀기) 버튼이 숨었다가 약 0.5초 안에 다시 다 보입니다**(5차 코멘트, 6차 2배 빠르게, 7차 0.5초 — 화살표는 누르고 0.25초 뒤, 밀기는 멈추고 0.1초 뒤부터 0.25초 동안 서서히). 그 전에 사람이 위아래로 스크롤하거나 사진을 톡 누르면 바로 서서히 나타나고, 사진이 늦게 떠도 3.5초 안에는 나타납니다(10/3 4차 코멘트: 2초 → 1초, 상세를 다시 열 때 바로 뜨던 문제 고침). **상세 화면은 옆으로 밀리지 않습니다**(가로 넘침 없음). | 화면·흐름 |
| F2-AC2c | 화면 아래에 **붙박이 막대**를 둡니다: **가고 싶어요 · 공유 · 길찾기(카카오맵)**. 가고 싶어요를 누르면 '담았어요'로 바뀌고 수첩의 '가고 싶은 곳'에 들어갑니다. 다시 누르면 뺍니다. 이 휴대폰에만 저장합니다. | 단위·화면 |
| F2-AC2d | (비교안, 사용자 결정 전) 주소에 `?motion=1`을 붙이면 장면 상세의 **지금 사진만** 14초 동안 한 번 아주 천천히 움직입니다. 옆으로 긴 사진은 좌우로 밀고, 그 밖은 6% 확대하며, 사진의 초점에서 멈춥니다. 사진을 넘기면 새로 시작하고, '동작 줄이기' 설정이면 움직이지 않습니다(`docs/design-guide.md` 6-1). | 단위·화면 |
| F2-AC3 | **작가 글 대목은 브런치 원문 그대로**입니다(한 글자라도 다르면 자동 검사가 막습니다). 대목 아래에 "— 이상호, ○번째 여행"이라고 출처를 적습니다. | 데이터 규칙 |
| F2-AC4 | 작가가 아직 확인하지 않은 항목(가장 좋은 때, 한 줄 소개, 가는 곳)에는 작은 **'초안'** 꼬리표가 붙습니다. | 화면 |
| F2-AC5 | 길찾기를 처음 누르면 **카카오맵 / 네이버지도** 중에서 고릅니다. 고른 앱은 이 휴대폰에 기억해 두고, 다음부터는 바로 열립니다. 카드 아래 "길찾기 앱 바꾸기"로 다시 고를 수 있습니다. 티맵은 실제 휴대폰에서 확인한 뒤 추가합니다. | 단위·화면·실기기 |
| F2-AC6 | 길찾기는 **이름이 아니라 좌표**로 열고, 목적지는 풍경 지점이 아니라 **주차장·입구 좌표**입니다(화면에 '가는 곳'을 따로 적지는 않음). | 단위·데이터 규칙(장면–가는 곳 15km 안) |
| F2-AC7 | PC에서는 카카오맵 웹으로 엽니다. 네이버지도 앱 주소는 PC에서 열리지 않기 때문입니다. | 단위 |
| F2-AC8 | **준비 중 핀**을 누르면 이름, 다녀온 날, "작가가 글을 다듬고 있어요. 브런치에 발행되면 여기에 이야기가 채워져요"만 나옵니다. 사진, 본문, 길찾기는 없습니다. | 화면·데이터 규칙 |
| F2-AC9 | **공유** 버튼을 누르면 휴대폰 공유 창(카카오톡 등)이 열립니다. 공유 창이 없는 브라우저에서는 주소를 복사하고 "주소를 복사했어요"라고 알립니다. 받은 사람은 같은 카드를 봅니다. *(결정 필요 3)* | 흐름 |
| F2-AC10 | 사진을 못 불러오면 빈 회색 자리와 "사진은 브런치에서 볼 수 있어요"를 보여 줍니다. 사진은 화면에 보일 때만 불러옵니다. | 화면 |
| F2-AC12 | **추천 시기**는 날짜로 보여 줍니다(예: 추천 시기 10월 말~11월 초). 꽃·단풍·억새·눈 장면에는 같은 상자 안에 "단풍 드는 때는 해마다 1~2주씩 달라져요. 떠나기 전 올해 단풍 소식을 확인하세요" 안내와 **올해 소식 찾아보기** 링크를 붙입니다. 링크는 네이버 검색으로, **꽃·단풍은 장소가 아니라 '누른 해 + ○○지도'**(단풍 → '2026 단풍지도', 벚꽃 → '2026 벚꽃지도', 그 밖의 꽃 → '2026 꽃지도', 글자 '올해 단풍지도 찾아보기 ›'), **눈·억새는 '장소 + 키워드'**(예: '발왕산 상고대 눈' — 그곳 CCTV·눈 소식이 나옴)로 찾습니다(10/3 6차 코멘트, `src/domain/timingNotice.ts`). | 단위·화면 |
| F2-AC13 | **작가 부부가 다녀온 곳**(제철 아님) 장면에는 "사진은 작가 부부가 8월에 다녀온 모습이에요"처럼 사진의 계절을 밝힙니다(일 년 내내 볼 수 있는 곳은 아래 추천 시기 칸이 '일 년 내내'로 알려 줌). | 화면 |
| F2-AC11 | **공모전 수상 대비:** 응모작 표시가 켜진 글은 스위치 하나로 **링크 카드**(사진 1장, 제목, 다녀온 날, 한 줄 소개, 브런치 링크)로 바뀝니다. | 단위·화면 |
