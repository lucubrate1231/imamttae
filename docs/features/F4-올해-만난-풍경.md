# F4. 저장한 곳 (옛 '내 수첩 · 올해 만난 풍경')

**한 줄:** 가고 싶은 곳을 지금 가기 좋은 순으로 모아 바로 길찾기하고, 다녀온 곳에는 장소 도장이 해마다 쌓입니다. 로그인 없이 이 휴대폰에만 저장합니다.

> **10/4 사용자 결정(D24~D26)으로 다시 썼습니다.** 옛 안(풍경 13칸 도장판, 도장판에서 바로 '봤어요', "무엇을 보셨어요?", 만난 곳 쌓기)은 쓰지 않습니다. 파일 이름은 링크가 깨지지 않게 그대로 둡니다.
> **화면:** 디자인 캔버스 [④줄 '저장한 곳'](https://claude.ai/artifact/RcKZdmgsTKWB8aH1LmV7iE) 9화면이 기준입니다(옛 도장판 7화면은 맨 아래 '옛 안 · 보관' 줄). 캔버스는 사용자 계정에서만 열리므로 이 문서와 [`docs/design-guide.md`](../design-guide.md) 6-2·9장만 보고도 만들 수 있게 적었습니다.
> **요구사항의 출처**는 프로젝트 문서 PRD 3-2장입니다. **따옴표 안 화면 글자는 design-guide 10장 '화면 글자 표'가 기준**입니다(10/4 사용자 — 화면 글자는 디자인 세션이 화면을 보며 정함. D28 [저장]/[저장됨], D29 상태 표시 '지금 좋아요', D30 '작가').

## 화면
1. **저장한 곳 탭** (`#/saved` — 주소 이름은 제안, 아래 메뉴 셋째 칸 **'저장한 곳'**): 제목 '저장한 곳' → 제철 알림 카드(있을 때) → **가고 싶은 곳** → **다녀온 곳**(도장 모음) → "이 휴대폰에만 저장돼요" 안내 + 홈 화면에 두기 → 아래 메뉴.
2. **장면 상세에 생기는 것:** [저장]을 누른 뒤의 안내 줄, 저장한 장면의 **[다녀왔어요]** 상자, **도장 찍히는 순간**, 다녀온 장면의 '○월 ○일에 다녀왔어요' 상자.
3. **첫 화면(지금 풍경)** 머리 아래의 제철 알림 카드.

## 계산·저장에 쓰는 말
저장 규칙(저장 형식, 새해 처리, 저장이 막힐 때)은 Codex 일 2가 만듭니다. Claude Code가 이 문서를 기준으로 `docs/tasks/`의 일 2 문서를 새 범위로 고쳐 씁니다.
- **가고 싶은 곳:** 장면 번호 + 저장한 날.
- **다녀온 곳:** 장면 번호 + 다녀온 날(한국 날짜) + **그때의 장소 이름과 대표 풍경**(장면이 나중에 숨겨지거나 바뀌어도 도장이 남도록).
- **대표 풍경:** 그 장면의 풍경 종류 중 첫 번째(`types[0]`). 도장 그림을 고를 때 씁니다.
- **지금 가기 좋은 순:** ① **지금**(오늘이 추천 시기 안, 화면 표시 '지금 좋아요' — 추천 시기가 먼저 끝나는 곳 먼저, 같으면 이름순, D23과 같은 규칙) → ② **일 년 내내** → ③ **곧**(추천 시기가 다음 달에 시작) → ④ **그 밖**(추천 시기가 빨리 오는 순). ③·④는 같으면 이름순.
- **한 곳 한 해 도장 하나:** 같은 장소는 한 해에 도장이 하나입니다. 다음 해에 다시 다녀오면(다시 저장한 뒤) 그해의 새 도장이 생깁니다.
- **해마다 묶기:** 다녀온 날의 연도(한국 날짜)로 묶습니다. 날짜를 지난해로 고치면 그해 묶음으로 옮겨집니다.

| F4-AC6 | 다녀온 장면을 다시 열면 상자 자리에 도장과 "10월 4일에 다녀왔어요", 상자 오른쪽 끝에 **[날짜 변경]**이 나옵니다(10/4 사용자가 캔버스에서 고침). 날짜는 고칠 수 있습니다(D10 — 주말에 다녀와 며칠 뒤 누르는 경우, 12월 말 여행을 1월에 누르는 경우). 다녀온 기록을 지우는 **취소**(지우면 도장이 없어지고 가고 싶은 곳으로 돌아감)는 자리를 정하는 중입니다(아래 '정해야 할 것'). | 흐름 |

## 알려진 한계 (알파 전에 실기기로 확인 — Claude Code)
- 저장은 **그 휴대폰의 그 브라우저**에만 됩니다. 카카오톡 안에서 연 화면, 사파리·크롬, 아이폰 홈 화면에 둔 앱은 저장을 서로 따로 둘 수 있습니다. 따로라면 카톡 링크로 들어와 저장한 곳이 홈 화면 앱에서는 안 보이므로, 안내 문구를 "홈 화면에 두고 여시면 늘 같은 곳에 모여요" 쪽으로 바꿉니다(PRD 3-2장).

## 정해야 할 것
- **도장 그림 스타일**(사용자): 디자인 세션의 힉스필드 시안 4가지(캔버스 ④줄 '도장 스타일 비교'). 정해지면 풍경 13가지 그림을 만들어 `public/`에 넣는 일은 그때 정합니다(192px WebP 한 장 15~29KB).
- **다녀온 기록 취소의 자리**(사용자): 10/4 캔버스에서 '취소'가 빠졌습니다. 안: ① [날짜 변경]을 누르면 뜨는 판 안에 '다녀온 기록 지우기' ② 상자에 '취소'를 다시 둠 ③ 취소 없이 둠(잘못 누르면 되돌릴 길이 없음).
- **문구**: 디자인 세션이 design-guide 10장에서 정합니다(10/4 사용자). 기획은 말의 원칙과 결정(D번호).
