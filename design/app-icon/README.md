# 앱 아이콘 원본

10/7 사용자가 고른 아이콘이에요. 흰 바탕에 엎어진 컵처럼 단순한 두 봉우리가 서로 비치고(겹친 면이 진하게), 해는 산 뒤로 가려져요. 쓰는 규칙과 고른 까닭은 `docs/design-guide.md` 11-6에 있어요.

| 파일 | 무엇 |
|---|---|
| `app-icon.svg` | 원본(일반). 그림 폭이 칸의 약 72% |
| `app-icon-maskable.svg` | 원본(안드로이드용). 그림이 가운데 동그라미(지름 80%) 안 |
| `favicon.svg` | 원본(브라우저 탭용). 바탕 없이 그림을 크게 |
| `app-icon-1024.png` · `app-icon-maskable-1024.png` | 위 SVG를 1024px로 뽑은 것 |

- 앱에서 쓰는 크기별 파일은 `public/brand/`에 있어요. 크기를 더 만들 때는 SVG를 크게 뽑은 뒤 줄여 주세요.
  - `icon-512`·`icon-192`·`apple-touch-icon-180` ← `app-icon.svg`
  - `icon-maskable-512`·`icon-maskable-192` ← `app-icon-maskable.svg`
  - `favicon-48`·`favicon-32` ← `favicon.svg`(바탕 투명)
- 색: 뒷산 #16C060 · 앞산 #0A9A48(둘 다 78% 불투명 — 흰 바탕 위에서 #49CE83 · #40B070, 겹친 면 #18A555) · 해 #FFB400 · 바탕 #FFFFFF.
- 해가 산을 통해 비치지 않게, SVG는 산 모양의 흰 바탕을 먼저 깔고 그 위에 비치는 산을 그려요.
- 디자인 세션이 직접 그린 벡터 그림이에요. 이 모양에 이르기까지 비교한 안(한글 '때'·'이맘때', 산과 해 6안, 간격 셋)은 디자인 캔버스 ⑩줄에 있어요.
- 옛 아이콘 '나'안(10/4~10/7, 달력 한 장 안에 두 봉우리와 해)은 git 기록에 있어요.
